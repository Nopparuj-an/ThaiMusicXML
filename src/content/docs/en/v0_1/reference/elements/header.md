The `<header>` element contains score metadata and the structure layout.

## Parent

[`<thai-score>`](/en/v0_1/reference/elements/thai-score/)

## Children

In order:

1. [`<title>`](/en/v0_1/reference/elements/title/) - required
2. [`<composer>`](/en/v0_1/reference/elements/composer/) - optional
3. [`<structure>`](/en/v0_1/reference/elements/structure/) - required

## Example

```xml
<header>
  <title>Lao Duang Duen</title>
  <composer>Traditional</composer>
  <structure>...</structure>
</header>
```
