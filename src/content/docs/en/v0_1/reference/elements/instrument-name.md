---
title: <instrument-name>
description: The name of an instrument
---

The `<instrument-name>` element gives the name of an instrument.

## Parent

[`<part>`](/en/v0_1/reference/elements/part/)

## Content

Text. Use the English name or the Thai name.

## Example

```xml
<instrument-name>Ranat Ek</instrument-name>
```

```xml
<instrument-name>ฉิ่ง</instrument-name>
```

## Rendering

On a solo score the instrument name does not print by default. On an ensemble score it is not printed by default and instead labels the part inside an editor. See [Instrument names](/en/v0_1/reference/rendering/#instrument-names).
