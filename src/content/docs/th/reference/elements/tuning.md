องค์ประกอบ `<tuning>` ระบุว่าเสียงในระบบเสียงของโน้ตเพลงฉบับนี้ตรงกับระดับเสียงจริงเสียงใด

ค่า `pitch` บอกเสียงในระบบเสียงไทย ไม่ได้บอกความถี่ ด คือเสียงแรกของระบบ ไม่ว่าวงจะตั้งเสียงไว้ที่ใดก็ตาม ถ้าไม่มี `<tuning>` เอกสารก็บอกได้แค่ว่าจะเล่นอะไรเมื่อเทียบกับวง แต่ไม่ได้บอกว่าเสียงจริงอยู่ตรงไหน ซึ่งพอสำหรับพิมพ์โน้ตออกมา แต่ไม่พอสำหรับทำให้มันดัง

## องค์ประกอบแม่

[`<header>`](/th/reference/elements/header/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| ----------- | -------- | ------ | ---------------------------------------- |
| `reference` | ใช่ | สตริง | ระบบเสียงที่ใช้เทียบ ด ดูด้านล่าง |

## ค่า

`reference` เป็นสตริงอิสระ ค่าข้างล่างนี้เป็นค่าที่ควรสะกดให้ตรงกันไว้ แต่รายการนี้เป็นจุดตั้งต้น ไม่ใช่ชุดปิด

| ค่า | คำอธิบาย |
| ----- | ----------- |
| `pi-phat-mai-khaeng` | ปี่พาทย์ไม้แข็ง ที่ระดับเสียงอ้างอิงกรมศิลปากร |
| `khrueang-sai` | เครื่องสาย และมโหรี ที่ระดับเสียงอ้างอิงกรมศิลปากร |
| `c-major` | ด ออกเสียงเป็น C เป็นตัวเลือกปกติของสื่อการสอนและโน้ตที่ใช้ร่วมกับเครื่องดนตรีสากล |
| `bb-major` | ด ออกเสียงเป็น B♭ เป็นค่าที่ใกล้เคียงที่สุดสำหรับวงเครื่องสายไทย |

ระบบเสียงมีมากกว่าสี่ค่านี้ การปิดรายการไว้ตอนนี้จึงเท่ากับปฏิเสธโน้ตเพลงที่อธิบายได้ด้วยชื่อซึ่งรายการยังไปไม่ถึง ตัวตรวจสอบจึงรับสตริงอะไรก็ได้ แล้วเตือนเมื่อเจอค่าที่ไม่รู้จัก วิธีนี้ยังจับ `c-majro` ได้ โดยไม่ทำให้ระบบเสียงที่ไม่คุ้นกลายเป็นเอกสารที่ผิด [`<nathap>`](/th/reference/elements/nathap/) เปิดกว้างด้วยเหตุผลเดียวกัน ส่วน [`<chan>`](/th/reference/elements/chan/) ไม่เปิด เพราะห้าระดับนั้นเป็นชุดที่ครบอยู่แล้ว

## ตัวอย่าง

```xml
<header>
  <title>แขกบรเทศ ชั้นเดียว</title>
  <tuning reference="khrueang-sai" />
</header>
```

## หมายเหตุ

- ระบบเสียงไทยแบ่ง octave ออกเป็นเจ็ดขั้นที่เกือบเท่ากัน กุญแจเสียงสากลจึงไม่มีอันไหนตรงพอดีสักอัน ค่า `c-major` และ `bb-major` บอกการเทียบที่ใกล้ที่สุด ไม่ได้บอกว่าตรงกันทุกประการ
- `<tuning>` จะมีหรือไม่มีก็ได้ โน้ตเพลงที่ทำไว้อ่านอย่างเดียว หรือที่ไม่รู้ว่าตั้งเสียงไว้อย่างไร จะละไว้ก็ได้

## การสอดคล้องมาตรฐาน

- `reference` เป็นแอตทริบิวต์ที่ต้องมี และรับสตริงที่ไม่ว่างค่าใดก็ได้
- ตัวตรวจสอบควรเตือนเมื่อ `reference` อยู่นอกรายการแนะนำข้างบน และต้องไม่ปฏิเสธเอกสารนั้น
- `<header>` หนึ่งตัวมี `<tuning>` ได้ไม่เกินหนึ่งตัว ดู [`<header>`](/th/reference/elements/header/)
