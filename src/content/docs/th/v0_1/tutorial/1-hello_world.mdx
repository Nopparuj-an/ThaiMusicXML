## คำอธิบาย

ต่อไปนี้คือคำอธิบายแต่ละองค์ประกอบ

```xml
<?xml version="1.0" encoding="UTF-8"?>
```

บรรทัดนี้คือการประกาศ XML บอกว่าเอกสารนี้เป็น XML และเข้ารหัสแบบ UTF-8

```xml
<thai-score xmlns="https://thaimusicxml.anan.ovh/ns/0.1" version="0.1">
```

`<thai-score>` คือรากของเอกสาร ThaiMusicXML แอตทริบิวต์ `xmlns` ประกาศเนมสเปซของ ThaiMusicXML ซึ่งเป็นสิ่งที่เครื่องมือใช้แยกองค์ประกอบเหล่านี้จากคำศัพท์ XML อื่น และใช้ตัดสินว่าจะอ่านไฟล์นี้ได้หรือไม่ ส่วน `version` บันทึกว่าไฟล์อ้างอิงสเปกรุ่นใด

```xml
<header>
  <title>Lao Duang Duen</title>
</header>
```

`<header>` เก็บข้อมูลเมตาของโน้ต ต้องมี `<title>` ซึ่งในตัวอย่างนี้คือชื่อเพลงไทย และอาจมี `<composer>` กับ `<tuning>` เพิ่มเติมได้

```xml
<structure>
  <section id="s1" name="ท่อน 1" />
</structure>
```

`<structure>` กำหนดโครงสร้างของโน้ต แต่ละ `<section>` มี `id` ที่ `<section-ref>` ใช้อ้างอิงภายหลังเพื่อแนบข้อมูลดนตรี และมี `name` เป็นป้ายให้ผู้อ่านได้ถ้าต้องการ ลำดับของท่อนในโน้ตคือตำแหน่งของ `<section>` แต่ละตัวที่ปรากฏใน `<structure>`

```xml
<ensemble>
  <part id="P1">
    <instrument-name>Ranat Ek</instrument-name>
  </part>
</ensemble>
```

`<ensemble>` แสดงรายชื่อเครื่องดนตรีทั้งหมด `<part>` แต่ละตัวมี `id` ที่ไม่ซ้ำกันและ `<instrument-name>` ตัวอย่างนี้มีระนาดเอก (ระนาดเอก, ระนาดไทย) เพียงตัวเดียว

```xml
<part-data part="P1">
  <section-ref section="s1">
    <line number="1">
      <measure number="1">
        <rest/><rest/><rest/><rest/>
      </measure>
      <measure number="2">
        <rest/><rest/><rest/><rest/>
      </measure>
      <measure number="3">
        <rest/><note pitch="ด"/><note pitch="ร"/><note pitch="ม"/>
      </measure>
      ...
    </line>
  </section-ref>
</part-data>
```

`<part-data>` บรรจุข้อมูลดนตรีของพาร์ตหนึ่ง แอตทริบิวต์ `part` ระบุว่าเป็นพาร์ตใดใน `<ensemble>` ส่วน `<section-ref>` ที่อยู่ข้างในเชื่อมโยงไปยังท่อนใน `<structure>` ดนตรีจัดเรียงเป็นองค์ประกอบ `<line>` แต่ละบรรทัดมี `<measure>` พร้อมแอตทริบิวต์ `number`

โน้ตใช้ชื่อระบบเสียงไทยในแอตทริบิวต์ `pitch` แต่ละดีกรีมีการสะกดสามแบบใช้แทนกันได้ `pitch="1"`, `pitch="D"`, และ `pitch="ด"` จึงเป็นโน้ตเดียวกัน เพลงนี้ใช้ห้าจากเจ็ดดีกรี:

| ตัวเลข | ไทย | โรมัน | ซอลเฟจ |
| ------ | ---- | --------- | ------- |
| 1      | ด    | D         | Do      |
| 2      | ร    | R         | Re      |
| 3      | ม    | M         | Mi      |
| 4      | ฟ    | F         | Fa      |
| 5      | ซ    | S         | Sol     |
| 6      | ล    | L         | La      |
| 7      | ท    | T         | Ti      |

คอลัมน์ซอลเฟจมีไว้ช่วยอ่านออกเสียงตารางเท่านั้น สามคอลัมน์ทางซ้ายคือค่า `pitch` ที่ใช้ได้จริง

เติม ํ (นิคหิต) ต่อท้ายชื่อโน้ตเพื่อยกขึ้นหนึ่ง octave เติม ฺ (พินทุ) เพื่อลดลงหนึ่ง octave เช่น `ดํ` คือ ด ที่สูงขึ้นหนึ่ง octave และ `ทฺ` คือ ท ที่ต่ำลงหนึ่ง octave ตัวปรับใช้ได้กับการสะกดทั้งสามแบบ รายละเอียดทั้งหมดอยู่ในหน้า [โน้ต ตัวหยุด และ octave](/th/v0_1/tutorial/4-notes_and_octaves/)

```xml
<rest/>
```

ตัวหยุดเป็นองค์ประกอบปิดตัวเองที่ไม่มีแอตทริบิวต์ ใช้เวลาหนึ่งจังหวะเท่ากับโน้ต และหมายความว่าเครื่องดนตรีไม่ตีเสียงใหม่ในจังหวะนั้น โน้ตไทยไม่มีเครื่องหมายการประคองเสียง เสียงที่ยังก้องอยู่ใต้ตัวหยุดถัดไปจึงเป็นพฤติกรรมปกติของเครื่องดนตรีเอง ไม่ใช่สิ่งที่โน้ตต้องบันทึก

ไฟล์นี้คือไฟล์ ThaiMusicXML ที่สมบูรณ์แล้ว ขั้นต่อไป ดู [โครงสร้างไฟล์](/th/v0_1/tutorial/2-file_structure/) เพื่อเรียนรู้วิธีเพิ่มเครื่องดนตรีหลายตัว หมายเหตุประกอบ และทิศทางการแสดง
