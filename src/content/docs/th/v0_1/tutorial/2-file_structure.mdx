## ส่วนหัว

`<header>` อาจมี `<composer>` ควบคู่ไปกับ `<title>`:

```xml
<header>
  <title>ลาวดวงเดือน</title>
  <composer><text align="right">ทำนอง: พระเจ้าบรมวงศ์เธอ กรมหมื่นพิไชยมหินทโรดม</text></composer>
</header>
```

เช่นเดียวกับ `<annotation>` องค์ประกอบ `<composer>` อาจใส่เป็นข้อความธรรมดาหรือมี `<text>` เป็นลูกพร้อมแอตทริบิวต์ `align` ในที่นี้บรรทัดผู้แต่งจัดชิดขวา

## โครงสร้าง

องค์ประกอบ `<structure>` บรรจุโครงสร้างโน้ต อาจมีหมายเหตุประกอบ ทิศทางการแสดง ท่อน และการซ้ำ:

```xml
<structure>
  <direction>
    <nathap value="ลาว" />
    <chan value="2" />
    <bpm>60</bpm>
  </direction>
  <repeat times="2">
    <annotation>ท่อน 1</annotation>
    <section id="s1" name="ท่อน 1" />
    <annotation>
      <text align="right">(กลับต้น)</text>
    </annotation>
  </repeat>
</structure>
```

- **`<direction>`**: ทิศทางการแสดงที่มีผลกับทั้งโน้ต
  - `<nathap>` ตั้งชื่อลูปกลอง ในที่นี้คือหน้าทับลาว
  - `<chan>` กำหนดชั้น (ชั้นจังหวะ) `value="2"` หมายถึงสองชั้น ชั้นไม่ใช่จังหวะเวลา เป็นการเว้นระยะรอบฉิ่ง ดู [แบบจำลองโน้ต](/th/v0_1/tutorial/3-the_score_model/) สำหรับความแตกต่าง
  - `<bpm>` กำหนดจังหวะที่ 60 จังหวะต่อนาที
- **`<repeat times="2">`**: คลุมท่อนด้วย `<repeat>` เพื่อเล่นมากกว่าหนึ่งครั้ง ในที่นี้ท่อน 1 เล่นสองครั้ง
- **`<annotation>`**: ข้อความอิสระ ใน `<structure>` หมายเหตุประกอบใช้ตั้งชื่อท่อนและเพิ่มบันทึกการแสดง `<text align="right">(กลับต้น)</text>` บอกผู้เล่นให้กลับไปต้นท่อน

## การนับบรรทัดและห้อง

การนับเลขห้องและบรรทัดภายในองค์ประกอบแม่ของตัวเอง บรรทัดเริ่มนับจาก `1` ในแต่ละ `<section-ref>` ส่วนห้องเริ่มนับจาก `1` ในแต่ละ `<line>`:

```xml
<section-ref section="s1">
  <line number="1">
    <measure number="1">...</measure>
    <measure number="2">...</measure>
  </line>
  <line number="2">
    <measure number="1">...</measure>
  </line>
</section-ref>
```

ลำดับของท่อนคือตำแหน่งของ `<section>` แต่ละตัวเมื่อเทียบกับตัวอื่นใน `<structure>` ไม่ใช่จากแอตทริบิวต์ การซ้ำท่อนไม่เปลี่ยนหมายเลขบรรทัดหรือห้อง การเล่นรอบที่สองเริ่มนับใหม่จากบรรทัด 1 ห้อง 1 ดู [ท่อน การซ้ำ และจุดจบ](/th/v0_1/tutorial/6-sections_repeats_endings/) สำหรับการซ้อนซ้ำและ `<line-repeat>`

## เครื่องดนตรีหลายตัว

`<ensemble>` อาจมีหลายพาร์ต:

```xml
<ensemble>
  <part id="P1">
    <instrument-name>ระนาดเอก</instrument-name>
    <instrument-short-name>รน.เอก</instrument-short-name>
  </part>
  <part id="P2" type="unpitched">
    <instrument-name>ฉิ่ง</instrument-name>
  </part>
</ensemble>
```

P1 คือระนาดเอก `<instrument-short-name>` ให้ป้ายชื่อสั้นสำหรับโน้ตที่มีพื้นที่จำกัด

P2 คือฉิ่ง เพิ่ม `type="unpitched"` หมายความว่าโน้ตใช้ `sound` แทน `pitch`:

```xml
<rest/><rest/><rest/><note sound="ฉิ่ง"/>
```

`sound="ฉิ่ง"` คือจังหวะเปิด และ `sound="ฉับ"` คือจังหวะปิด เพลงนี้เป็นสองชั้น ฉิ่งจึงตีหนึ่งครั้งต่อห้อง สลับฉิ่งกับฉับทุกห้อง ตัวหยุดสามตัวก่อนแต่ละจังหวะเติมช่องที่เหลือ

## ข้อมูลพาร์ต

เครื่องดนตรีแต่ละตัวมีองค์ประกอบ `<part-data>` ของตัวเอง แอตทริบิวต์ `part` เชื่อมกลับไปยัง `<part>` ใน `<ensemble>`:

```xml
<part-data part="P1">
  <section-ref section="s1">
    <line number="1">
      <measure number="1"><rest/><rest/><rest/><rest/></measure>
      <measure number="2"><rest/><rest/><rest/><rest/></measure>
      <measure number="3"><rest/><note pitch="ด"/><note pitch="ร"/><note pitch="ม"/></measure>
      <measure number="4"><rest/><note pitch="ซ"/><rest/><note pitch="ด"/></measure>
      ...
    </line>
  </section-ref>
</part-data>
```

ทุก `<part-data>` มีโครงสร้างเหมือนกัน: `<section-ref>` เชื่อมโยงไปยังท่อน แล้วมี `<line>` และ `<measure>` แต่ละห้องมีช่องโน้ตสี่ช่องพอดี เพลงนี้มีสี่จังหวะต่อห้อง แต่ละจังหวะเป็นหนึ่งช่อง

สองห้องแรกของบรรทัด 1 เป็นตัวหยุดทั้งหมด ระนาดเอกเข้าในห้อง 3 ตัวหยุดหมายความว่าเครื่องดนตรีไม่ตีเสียงใหม่ในจังหวะนั้น ไม่ใช่ความเงียบ
