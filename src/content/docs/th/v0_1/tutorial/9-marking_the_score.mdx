[เครื่องดนตรีหลายตัวและโน้ตซ้อน](/th/v0_1/tutorial/7-ensembles_stacked/) เพิ่มหลายพาร์ตเข้ามาในโน้ต หน้านี้ครอบคลุมองค์ประกอบที่เปลี่ยนตารางเปล่าให้เป็นแผ่นโน้ตที่พิมพ์ได้จริง ได้แก่ เครื่องหมายคันชัก ข้อความที่ย่อไว้ หมายเหตุประกอบ และข้อมูลเมตา

## เครื่องหมายคันชัก

<Image src={bowSpans} width={200} alt="เครื่องหมายคันชัก" />

`<bow>` ทำเครื่องหมายจุดเริ่มต้นและจุดสิ้นสุดของการใช้คันชักบนเครื่องสาย ใช้ `type="start"` คู่กับ `type="stop"` และมีแอตทริบิวต์ `direction` (`in` หรือ `out`):

```xml
<bow type="start" direction="out"/><note pitch="ด"/><note pitch="ร"/><bow type="stop"/><note pitch="ม"/>
```

ช่วงนี้ครอบคลุม ด และ ร จากนั้น ม เล่นโดยไม่มีเครื่องหมายคันชัก จากซออู้ในท่อน 1:

```xml
<measure number="3">
  <rest/><bow type="start" direction="out"/><note pitch="ด"/><note pitch="ร"/><bow type="stop"/><note pitch="ม"/>
</measure>
```

เครื่องหมายคันชักมีความยาวเป็นศูนย์ ไม่นับเป็นจังหวะ และข้ามขอบเขต `<group>`, `<measure>`, `<line>` ได้อย่างอิสระ ช่วงที่มีโน้ตเพียงตัวเดียวก็ใช้ได้ คือโน้ตตัวเดียวที่มีทั้ง start และ stop

## วงเล็บ

<Image src={parenthesis} width={200} alt="วงเล็บ" />

`<parenthesis>` ทำเครื่องหมายว่าข้อความนั้นถูกย่อหรือจาง เพิ่ม `dim="true"` เพื่อทำให้จางลง:

```xml
<parenthesis type="start" dim="true"/><note pitch="ด"/><note pitch="ร"/><note pitch="ด"/><note pitch="ล"/><parenthesis type="stop"/>
```

จากระนาดเอกในท่อน 2 ข้อความที่จางข้ามสองห้อง:

```xml
<measure number="1">
  <parenthesis type="start" dim="true"/><rest/><rest/><rest/><note pitch="ร"/>
</measure>
<measure number="2">
  <note pitch="ด"/><note pitch="ด"/><note pitch="ด"/><note pitch="ด"/><parenthesis type="stop"/>
</measure>
```

เครื่องหมายวงเล็บมีความยาวเป็นศูนย์และข้ามขอบเขตได้อย่างอิสระเช่นเดียวกับเครื่องหมายคันชัก

## BR: ขึ้นบรรทัดใหม่

`<br>` เปิดช่องว่างแนวตั้งในโน้ตที่เรนเดอร์ เป็นองค์ประกอบปิดตัวเองที่ไม่มีแอตทริบิวต์:

```xml
<structure>
  <br/>
  <annotation>เพลงลาวดำเนินเกวียน ...</annotation>
  <br/>
  <direction>...</direction>
</structure>
```

โน้ตหลักใช้ `<br>` เว้นระยะห่างระหว่างหมายเหตุประกอบกับบล็อกทิศทางการแสดง ใช้เท่าที่จำเป็น โครงสร้างตารางมีการจัดระเบียบอยู่แล้ว

## หมายเหตุประกอบและการจัดตำแหน่ง

<Image src={annotations} width={600} alt="หมายเหตุประกอบและการจัดตำแหน่ง" />

`<annotation>` ร่วมกับ `<text align>` ควบคุมตำแหน่งข้อความในเซลล์:

```xml
<annotation>
  <text align="left">ท่อน 1</text>
  <text align="center">Lao Duang Duen</text>
  <text align="right">หน้า 1</text>
</annotation>
```

ค่า `align` เป็นได้ทั้ง `left`, `center`, หรือ `right` ข้อความธรรมดาในหมายเหตุประกอบจัดชิดซ้ายโดยปริยาย

หลักการออกแบบคือ ถ้าอยากให้พิมพ์ออกมา ก็พิมพ์ไว้เอง แอตทริบิวต์ `name` ของท่อนเก็บไว้ภายในไฟล์ สิ่งที่ปรากฏบนหน้ากระดาษคือสิ่งที่ผู้เรียบเรียงใส่ไว้ใน `<annotation>` หรือเครดิต

## เครดิตและข้อมูลอื่น ๆ

<Image src={credits} width={600} alt="เครดิตและข้อมูลอื่น ๆในส่วนหัว" />

`<header>` อาจมีองค์ประกอบข้อมูลเมตาหลายอย่าง:

```xml
<header>
  <title>ลาวดวงเดือน</title>
  <composer><text align="right">ทำนอง: พระเจ้าบรมวงศ์เธอ กรมหมื่นพิไชยมหินทโรดม</text></composer>
  <lyricist><text align="right">เนื้อร้อง: พระเจ้าบรมวงศ์เธอ กรมหมื่นพิไชยมหินทโรดม</text></lyricist>
  <arranger><text align="right">รวบรวมและดัดแปลงจากหลายแหล่ง</text></arranger>
  <tuning reference="khrueang-sai"/>
  <license>PUBLIC DOMAIN</license>
</header>
```

- `<lyricist>` ระบุผู้แต่งเนื้อร้อง
- `<arranger>` ระบุผู้ดัดแปลงหรือผู้ถอดโน้ต
- `<tuning>` บันทึกระบบเสียง แอตทริบิวต์ `reference` ตั้งชื่อมาตรฐานการปรับเสียง
- `<license>` ระบุลิขสิทธิ์

องค์ประกอบเหล่านี้เป็นข้อมูลเมตาสำหรับไฟล์และเครื่องมือที่อ่านไฟล์ จะพิมพ์บนหน้ากระดาษหรือไม่ขึ้นอยู่กับการเรนเดอร์

## หน้าทับ

`<nathap>` บันทึกลูปกลองที่เพลงใช้เล่น อยู่ใน `<direction>` และเป็นข้อมูลเมตาในระดับเดียวกับ `<chan>`:

```xml
<nathap value="ลาว"/>
```

ข้อมูลนี้ส่งถึงเครื่องมือแก้ไขและเอนจินเล่นเสียง ไม่ได้สร้างป้ายพิมพ์ออกมา
