[โน้ต ตัวหยุด และ octave](/th/v0_1/tutorial/4-notes_and_octaves/) แสดงให้เห็นว่าทุกโน้ตและตัวหยุดใช้เวลาหนึ่งจังหวะ หน้านี้แนะนำองค์ประกอบ `<group>` ที่แบ่งจังหวะเดียวออกเป็นส่วนเท่า ๆ กัน เป็นแนวคิดที่เฉพาะกับ ThaiMusicXML มากที่สุด

หน้านี้ใช้ตัวอย่างจากเพลงแขกบรเทศ ซึ่งมีการแบ่งย่อยซับซ้อนกว่าลาวดวงเดือน

## กลุ่มคืออะไร

`<group>` ใช้พื้นที่หนึ่งจังหวะพอดี เท่ากับ `<note>` หรือ `<rest>` เดี่ยว จังหวะนั้นถูกแบ่งเท่า ๆ ระหว่างลูก: สองลูกแต่ละตัวได้ครึ่งจังหวะ สามลูกแต่ละตัวได้หนึ่งในสาม และอื่น ๆ

```xml
<!-- จังหวะ 3 แบ่งเป็นสองส่วน -->
<measure number="1">
  <note pitch="ด"/>
  <note pitch="ร"/>
  <group>
    <note pitch="ม"/>
    <note pitch="ซ"/>
  </group>
  <note pitch="ล"/>
</measure>
```

ห้องนี้มีสี่จังหวะ `<group>` ในจังหวะ 3 มีโน้ตสองตัว แต่ละตัวได้ครึ่งจังหวะ อีกสามจังหวะแต่ละตัวมีโน้ตตัวเดียว

กลุ่มต้องมีลูก `<note>` หรือ `<rest>` อย่างน้อยสองตัว ซ้อนกันไม่ได้ การแบ่งย่อยลึกเพียงชั้นเดียวใน v0.1

## ลูกตกตรงไหน

จังหวะนับที่ช่องสุดท้าย (ดู [แบบจำลองโน้ต](/th/v0_1/tutorial/3-the_score_model/)) ลูกตัวสุดท้ายของกลุ่มลงบนจังหวะพอดี ส่วนตัวก่อนหน้าถอยหลังจากจุดนั้น

นี่คือจุดที่การแบ่งย่อยแบบไทยแยกจากแบบตะวันตก ในโน้ตตะวันตก กลุ่มโน้ตเขบ็ตสองตัววางตัวแรกบนจังหวะแล้วตัวที่สองตามหลัง ใน ThaiMusicXML ตัวที่สองอยู่บนจังหวะ ส่วนตัวแรกนำไปสู่จุดนั้นจากข้างหน้า

ทำเครื่องหมายโน้ตที่ลงบนจังหวะเป็น `X` และโน้ตระหว่างจังหวะเป็น `O`:

```
โน้ตธรรมดา:   | - ร  -  ม      | →  | -  X  -  X  |
กลุ่มสองตัว:   | - (ร ม) - ซ   | →  | - (O X) - X |
กลุ่มสามตัว:  | -  -  - (ด ร ม)| →  | -  -  - (O O X) |
```

`<note>` ธรรมดาเป็น `X` เสมอ คือเป็นจังหวะ มีแต่กลุ่มเท่านั้นที่สร้าง `O` และเฉพาะลูกที่ไม่ใช่ตัวสุดท้าย

## ทำไมกลุ่มข้ามขอบเขตไม่ได้

กลุ่มใช้พื้นที่หนึ่งจังหวะพอดี ลูกแบ่งจังหวะนั้นระหว่างกัน แม้กลุ่มสามหรือสี่ตัวก็ยังอยู่ในช่วงเวลาเดียวกับโน้ตธรรมดาตัวเดียว กลุ่มไม่เคยใช้มากกว่าหนึ่งจังหวะ จึงล้นไปจังหวะก่อนหน้าไม่ได้ และข้ามขอบเขต `<measure>` หรือ `<line>` ไม่ได้

## กลุ่มที่มีตัวหยุด

กลุ่มผสมโน้ตกับตัวหยุดได้ จากฆ้องวงใหญ่ R ของแขกบรเทศ ท่อน 2 ห้อง 3:

```xml
<group>
  <rest/>
  <note pitch="ซ"/>
  <note pitch="ล"/>
</group>
```

นี่คือกลุ่มสามตัว ตัวหยุดใช้หนึ่งในสามของจังหวะ ซ ใช้อีกหนึ่งในสาม และ ล ลงบนจังหวะพอดี

## กลุ่มกับโน้ตธรรมดา

ห้องผสมโน้ตธรรมดากับกลุ่มได้ จากพาร์ตเดียวกัน ห้อง 6:

```xml
<note pitch="ดํ"/>
<rest/><rest/>
<group>
  <note pitch="รํ"/>
  <note pitch="มํ"/>
</group>
```

สี่จังหวะ: ดํ บนจังหวะ 1 ตัวหยุดสองตัวบนจังหวะ 2 และ 3 และกลุ่มสองตัวบนจังหวะ 4 โน้ตสองตัวในกลุ่มแต่ละตัวได้ครึ่งจังหวะ โดย มํ ลงบนจังหวะ

## Link: ทำเครื่องหมายท่าทาง

กลุ่มบอกว่าจังหวะแบ่งอย่างไร แต่ไม่ได้บอกว่าโน้ตเหล่านั้นเป็นการเคลื่อนมือชุดเดียวกัน หากต้องการบอกเช่นนั้น ให้เขียนช่วง [`<link>`](/th/v0_1/reference/elements/link/) ครอบไว้:

```xml
<note pitch="ด"/>
<link type="start"/>
<group>
  <note pitch="ร"/>
  <note pitch="ม"/>
</group>
<link type="stop"/>
<note pitch="ซ"/>
```

เส้นโค้งจะปรากฏเหนือ ร กับ ม ไม่เปลี่ยนการเล่น เพราะการแบ่งย่อยของกลุ่มอธิบายจังหวะอยู่แล้ว สิ่งที่เพิ่มคือความแน่นอน เนื่องจากกลุ่มแสดงโดยโน้ตชิดกันเท่านั้น และในห้องที่แน่นช่องว่างนั้นมีพื้นที่ทำงานน้อย

เพราะ `<link>` เป็นคู่ตัวกำกับ ไม่ใช่สิ่งที่กลุ่มถือเอง ช่วงจึงวิ่งเลยจังหวะที่เปิดไว้ได้:

```xml
<note pitch="ด"/>
<link type="start"/>
<group><note pitch="ร"/><note pitch="ม"/></group>
<group><note pitch="ซ"/><note pitch="ล"/></group>
<link type="stop"/>
<note pitch="ท"/>
```

เส้นโค้งเดียวเหนือโน้ตสี่ตัวสองจังหวะ นี่คือรูปแบบปกติของการรัวในเพลงไทย และเป็นเหตุผลที่เครื่องหมายนี้เป็นองค์ประกอบไม่ใช่แอตทริบิวต์บน `<group>` เพราะกลุ่มคือหนึ่งจังหวะพอดี ขณะที่ท่าทางมักไม่ใช่

### เข้าถึงแถวอื่น

เมื่อ `<part>` ที่ครอบมีแอตทริบิวต์ `stack` (หมายความว่าเครื่องดนตรีเขียนโน้ตข้ามหลายแถว) เส้นโค้งจะเข้าถึงแถวอื่นด้วย

จากแขกบรเทศ ท่อน 2 ห้อง 3 ทั้งสองแถวของฆ้องวงใหญ่:

ฆ้องวงใหญ่ R:

```xml
<link type="start"/>
<group>
  <rest/>
  <note pitch="ซ"/>
  <note pitch="ล"/>
</group>
<link type="stop"/>
```

ฆ้องวงใหญ่ L:

```xml
<group>
  <note pitch="ฟ"/>
  <rest/><rest/>
</group>
```

เครื่องดนตรีเล่น ฟ ซ ล ตลอดจังหวะนั้น เส้นโค้งจึงวิ่งจาก ฟ ในแถว L ไปยัง ล ในแถว R ไม่มีแถวใดถือปลายทั้งสอง บนเครื่องดนตรีที่มีหลายบรรทัด นี้บอกผู้เล่นว่าสองแถวเป็นท่าทางเดียวกัน

ประกาศฝั่งเดียวพอ ช่วงในแถวบนอธิบายการเชื่อมต่อไว้แล้ว ไม่ต้องทำเครื่องหมายสิ่งที่มันเข้าถึงด้วย ตัวกำกับทั้งสองต้องอยู่ในพาร์ตเดียวกันเสมอ เปิดในแถวหนึ่งแล้วปิดในอีกแถวไม่ได้

## สองพาร์ตแบ่งย่อยต่างกัน

พาร์ตต่างกันแบ่งจังหวะเดียวกันคนละแบบได้ เครื่องดนตรีหนึ่งอาจเล่นโน้ตธรรมดาขณะที่อีกเครื่องเล่นกลุ่มสามตัว ตารางยังจัดตำแหน่งตรงกันเพราะตำแหน่งจังหวะใช้ร่วมกันทุกพาร์ต

```xml
<!-- พาร์ต A: จังหวะ 2 เป็นโน้ตธรรมดา -->
<note pitch="ด"/><note pitch="ร"/><note pitch="ม"/><note pitch="ซ"/>

<!-- พาร์ต B: จังหวะ 2 เป็นกลุ่มสามตัว -->
<note pitch="ด"/><group><note pitch="ร"/><note pitch="ม"/><note pitch="ซ"/></group><note pitch="ม"/><note pitch="ล"/>
```

ทั้งสองห้องมีสี่จังหวะ ร ของพาร์ต A อยู่บนจังหวะ 2 กลุ่มของพาร์ต B แบ่งจังหวะ 2 เป็นสามส่วน โดย ซ ลงบนจังหวะ และ ร กับ ม ถอยหลังจากจุดนั้น จังหวะตรงกันแม้โน้ตจะไม่ตรง
