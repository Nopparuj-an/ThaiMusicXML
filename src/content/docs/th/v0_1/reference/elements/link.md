---

องค์ประกอบ `<link>` ระบุช่วงโน้ตว่าเป็นท่าทางเดียว (เช่น สะบัด) ที่เชื่อมต่อกัน และวาดเส้นโค้งที่บอกเช่นนั้น

## องค์ประกอบแม่

[`<measure>`](/th/v0_1/reference/elements/measure/) หรือ [`<group>`](/th/v0_1/reference/elements/group/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท                | คำอธิบาย              |
| ----------- | ------ | --------------------- | --------------------- |
| `type`      | ใช่    | `"start"` \| `"stop"` | ตัวเปิดหรือตัวปิดช่วง |

มีเพียงเท่านี้ [`<bow>`](/th/v0_1/reference/elements/bow/) มี `direction` และ [`<parenthesis>`](/th/v0_1/reference/elements/parenthesis/) มี `dim` กับ `mute` เพราะเป็นสิ่งที่ผู้เรียบเรียงเลือก แต่เส้นโค้งของ link ไม่ได้เลือก มันตามมาจากตำแหน่งที่โน้ตในช่วงตกลง

## ความหมาย

`<link type="start"/>` และ `<link type="stop"/>` ถัดไปที่พาร์ตเข้าถึงจะครอบช่วงหนึ่ง โน้ตระหว่างทั้งสองเป็นท่าทางเดียวกัน

เป็นคำแนะนำการแสดงผล ไม่มีผลต่อการเล่นหรือจังหวะ โน้ตอธิบายจังหวะอยู่แล้ว สิ่งที่เส้นโค้งเพิ่มคือความแน่นอนว่าโน้ตจัดกลุ่มกันอย่างไร

การจับคู่ตามลำดับเอกสารภายในรอบที่แก้ไขแล้ว เหมือน `<bow>` ตัวในห้องหนึ่งอาจถูกปิดด้วยตัวในห้องหรือบรรทัดถัดไป ช่วงจึงข้ามขอบเขต `<measure>`, `<group>`, และ `<line>` ได้ แต่ไม่ข้ามขอบเขตท่อน ดู [`<bow>`](/th/v0_1/reference/elements/bow/#ความหมาย) สำหรับผลของ [`<ending>`](/th/v0_1/reference/elements/ending/) และ [`<line-repeat>`](/th/v0_1/reference/elements/line-repeat/) กฎตรงกันทุกข้อ

### เส้นโค้งไปที่ใด

บนเครื่องดนตรีแถวเดียว เส้นโค้งอยู่เหนือโน้ตของช่วงเอง กลุ่มแสดงโดยโน้ตชิดกันเท่านั้น ในห้องที่แน่นช่องว่างนั้นมีพื้นที่ทำงานน้อย ช่วง link จึงเป็นวิธีที่ผู้เรียบเรียงบอกว่าการรัวชุดหนึ่งต้องไม่คลุมเครือ

บนเครื่องที่โน้ตข้ามหลายแถว (ดูแอตทริบิวต์ `stack` ของ [`<part>`](/th/v0_1/reference/elements/part/)) เส้นโค้งเข้าถึงแถวอื่นด้วย ระบุว่าแถวเหล่านั้นเป็นของท่าทางเดียว stack คือเครื่องดนตรีชิ้นเดียว ท่าทางจึงเป็นสิ่งที่เครื่องดนตรีนั้นเล่น ไม่ใช่สิ่งที่มือข้างใดข้างหนึ่งทำ

โน้ตที่เส้นโค้งเข้าถึงตามมาจากข้อนั้น ในแถวที่เขียนช่วง คือโน้ตระหว่างตัวกำกับทั้งสอง ในแถวโน้ตอื่นของเครื่องดนตรี คือโน้ตทุกตัวที่แถวนั้นเล่นในจังหวะที่ช่วงครอบ กฎทั้งสองต่างกันเพราะแถวตรงกันได้เพียงระดับหนึ่ง ทุกพาร์ตตรงกันเรื่องจำนวนจังหวะในห้อง (ดู [`<section-ref>`](/th/v0_1/reference/elements/section-ref/#การสอดคล้องมาตรฐาน)) แต่แถวหนึ่งอาจแบ่งจังหวะเป็นสองขณะอีกแถวแบ่งเป็นสาม ช่องโน้ตในแถวหนึ่งจึงไม่ระบุตำแหน่งใดเลยในอีกแถว จังหวะเป็นหน่วยที่ละเอียดที่สุดที่แถวใช้ร่วมกัน

ละเว้นตัวหยุดตลอด เพราะ[ตัวหยุดคือการไม่มีการโจมตีใหม่](/th/v0_1/reference/elements/rest/) ไม่มีสิ่งใดให้ท่าทางเข้าถึง

ตัวกำกับทั้งสองอยู่ในพาร์ตเดียวกันเสมอ เหมือน `<bow>` สิ่งที่ข้ามแถวคือการเข้าถึงของเส้นโค้ง ไม่ใช่ตัวช่วงเอง และการเข้าถึงนั้นเพียงพอ ช่วงที่เขียนในแถวบนและครอบสองจังหวะวาดเส้นโค้งที่เริ่มบนโน้ตในแถวล่างสุดและจบบนโน้ตในแถวบนได้อยู่แล้ว เพราะปลายทั้งสองหาจากการอ่านทั้ง stack ตลอดจังหวะเหล่านั้น `type="start"` ในแถวหนึ่งกับ `type="stop"` ในอีกแถวเป็นตัวกำกับค้างสองตัว ไม่ใช่ช่วง และไม่วาดสิ่งใด

## ตัวอย่าง

```xml
<!-- หนึ่งจังหวะ: เครื่องหมายเดียวกับที่กลุ่มเคยถือเอง -->
<measure number="1">
  <note pitch="ด"/>
  <link type="start"/>
  <group>
    <note pitch="ร"/>
    <note pitch="ม"/>
  </group>
  <link type="stop"/>
  <note pitch="ซ"/>
</measure>
```

```xml
<!-- สองจังหวะใต้เส้นโค้งเดียว คือสิ่งที่คู่ตัวกำกับให้ -->
<measure number="2">
  <note pitch="ด"/>
  <link type="start"/>
  <group><note pitch="ร"/><note pitch="ม"/></group>
  <group><note pitch="ซ"/><note pitch="ล"/></group>
  <link type="stop"/>
  <note pitch="ท"/>
</measure>
```

```xml
<!-- เปิดภายในกลุ่ม เพราะตัวกำกับอยู่ตรงที่ท่าทางเริ่ม -->
<measure number="3">
  <group>
    <note pitch="ดํ"/>
    <link type="start"/>
    <note pitch="ท"/>
  </group>
  <note pitch="ล"/>
  <link type="stop"/>
  <note pitch="ซ"/>
</measure>
```

## การสอดคล้องมาตรฐาน

- ในทุกรอบที่แก้ไขแล้วของท่อน `type="start"` ต้องถูกปิดด้วย `type="stop"` ที่ตรงกันก่อนที่ `type="start"` อื่นจะปรากฏ ช่วง link ไม่สามารถซ้อนหรือทับซ้อนกัน
- ในทุกรอบที่แก้ไขแล้ว `type="start"` ทุกตัวต้องมี `type="stop"` ที่ตรงกันภายใน `<section-ref>` เดียวกัน ช่วงที่เปิดค้างไว้เมื่อจบรอบไม่ถูกต้อง แม้อีกรอบจะปิดก็ตาม
- ช่วง link ไม่สามารถข้ามขอบเขต `<section>` ได้
- ตัวกำกับ `<link>` ภายใน [`<group>`](/th/v0_1/reference/elements/group/) ไม่มีความยาวและไม่นับรวมการแบ่งเท่าของจังหวะกลุ่มนั้น
- เมื่อ `<part>` ที่ครอบมี `stack` แถวอื่นอย่างน้อยหนึ่งต้องเป็นพาร์ตโน้ต หมายถึง `type="pitched"` หรือ `type="unpitched"` [พาร์ตเนื้อเพลง](/th/v0_1/reference/elements/part/#ประเภทพาร์ต) มี `stack` ได้ แต่ห้องเนื้อเพลงมีคำไม่ใช่จังหวะ จึงไม่มีตำแหน่งให้เส้นโค้งเข้าถึง ช่วง link ที่ stack ไม่มีแถวโน้ตอื่นไม่ถูกต้อง
- เมื่อ `<part>` ไม่มี `stack` เส้นโค้งทำเครื่องหมายโน้ตของช่วงเอง และไม่มีเงื่อนไขอื่นให้สอดคล้อง
- ตัวกำกับทั้งสองของช่วงต้องอยู่ในพาร์ตเดียวกัน `type="start"` ในแถวหนึ่งของ stack ปิดด้วย `type="stop"` ในอีกแถวไม่ได้ กรณีนั้นทำให้ช่วงแรกเปิดค้างเมื่อจบรอบและตัวที่สองไม่ได้ปิดสิ่งใด ซึ่งไม่ถูกต้องตามกฎข้างต้นอยู่แล้ว
- ข้ามแถว link อธิบายการเชื่อมต่อ จึงประกาศฝั่งเดียว การทำเครื่องหมายช่วงในแถวบนเป็นธรรมเนียม ไม่ต้องทำเครื่องหมายสิ่งที่มันเข้าถึงด้วย
- ช่วงที่มีโน้ตดังน้อยกว่าสองตัวไม่มีการรัวให้ทำเครื่องหมาย และไม่วาดสิ่งใด ไม่ถือเป็นข้อผิดพลาด

## หมายเหตุ

- link กับ [`<bow>`](/th/v0_1/reference/elements/bow/) จับคู่แยกกัน ช่วงหนึ่งจึงเปิดภายในอีกช่วงได้ ท่าทางที่มี bow ด้วยเป็นเรื่องปกติที่เขียนกัน
- บน stack สามแถว เส้นโค้งเข้าถึงทุกแถว ท่าทางที่ต้องเข้าถึงแถวเฉพาะหนึ่งและไม่อีกแถวระบุไม่ได้ใน v0.1 เช่นเดียวกับท่าทางที่ครอบจังหวะต่างกันในแต่ละแถว ช่วงมีขอบเขตเดียวและอ่านทุกแถวตลอดขอบเขตนั้น
