องค์ประกอบ `<instrument-name>` ให้ชื่อเครื่องดนตรี

## องค์ประกอบแม่

[`<part>`](/th/v0_1/reference/elements/part/)

## เนื้อหา

ข้อความ ใช้ชื่อภาษาอังกฤษหรือภาษาไทย

สำหรับแถวหนึ่งของ[เครื่องดนตรีที่ซ้อนแถว](/th/v0_1/reference/elements/part/#เครื่องดนตรีที่ซ้อนแถว) ชื่อนี้ยังบอกด้วยว่าเป็นแถวไหน เพราะแอตทริบิวต์ `row` บันทึกไว้เพียงตำแหน่ง เช่น `ฆ้องวงใหญ่ มือขวา` ระบุทั้งชื่อเครื่องดนตรีและมือไปพร้อมกัน

## ตัวอย่าง

```xml
<instrument-name>Ranat Ek</instrument-name>
```

```xml
<instrument-name>ฉิ่ง</instrument-name>
```

## การแสดงผล

ชื่อจะพิมพ์หรือไม่ขึ้นอยู่กับวง ดู [ชื่อเครื่องดนตรี](/th/v0_1/reference/rendering/#ชื่อเครื่องดนตรี) เมื่อชื่อนี้ยาวเกินไปสำหรับคอลัมน์ป้ายชื่อวงซึ่งมีพื้นที่ให้ใช้เพียงขอบหน้า [`<instrument-short-name>`](/th/v0_1/reference/elements/instrument-short-name/) จะเข้ามาแทนที่ตรงนั้น
