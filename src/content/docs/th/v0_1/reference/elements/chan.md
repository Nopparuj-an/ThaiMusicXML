องค์ประกอบ `<chan>` ตั้งระดับชั้นจังหวะ

ชั้นคือระบบชั้นจังหวะไทยที่กำหนดความหนาแน่นของจังหวะในการแสดง

## องค์ประกอบแม่

[`<direction>`](/th/v0_1/reference/elements/direction/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| --------- | -------- | ----------- | ---------------------------------------------- |
| `value`   | ใช่      | ค่าอีนัม | ระดับชั้น หนึ่งในห้าค่าด้านล่าง |

## ค่า

| ค่า | ชื่อ |
| ----- | --------- |
| `0.5` | ครึ่งชั้น |
| `1`   | ชั้นเดียว |
| `2`   | สองชั้น |
| `3`   | สามชั้น |
| `4`   | สี่ชั้น |

## ตัวอย่าง

```xml
<chan value="1" />
```

## หน้าที่

ในเวอร์ชัน 0.1 ค่านี้ไม่มีผลต่อการคำนวณใด ๆ `<chan>` เพียงบันทึกระดับชั้นไว้และส่งต่อให้ซอฟต์แวร์ที่อ่านไฟล์นำไปใช้

ค่านี้ไม่มีผลต่อจังหวะเวลา: [`<bpm>`](/th/v0_1/reference/elements/bpm/) เป็นตัวกำหนดอัตราของช่องโน้ต โดยจังหวะ bpm คงที่อยู่ที่สองช่องโน้ตเสมอไม่ว่าจะอยู่ชั้นใด โน้ตจึงคงอัตราเดิมไว้แม้เปลี่ยนระดับชั้น สิ่งที่เปลี่ยนไปคือฉิ่ง ซึ่งผู้เรียบเรียงเขียนไว้เป็นพาร์ตไม่มีระดับเสียงตามปกติ ไม่ได้ถูกสร้างขึ้นจากองค์ประกอบนี้ ตัวเล่นที่ไม่ได้ใช้ `<chan>` ก็ยังเล่นโน้ตได้ถูกต้อง

ค่านี้จึงเป็นเพียงเมตาดาต้า ไว้ให้ตัวแก้ไขแสดงผล ให้ห้องสมุดใช้จัดทำดัชนี หรือให้เครื่องเล่นนำไปใช้ตามที่เห็นสมควร ไม่ใช่คำสั่งที่รูปแบบไฟล์บังคับให้ซอฟต์แวร์ใดต้องทำตาม

## หมายเหตุ

- ชั้นไม่ได้เป็นตัวกำหนดจังหวะ เมื่อ [`<bpm>`](/th/v0_1/reference/elements/bpm/) คงที่ โน้ตจะคงอัตราเดิมไว้แม้เปลี่ยนชั้น สิ่งที่เปลี่ยนคือจำนวนช่องโน้ตที่ทำนองกระจายอยู่ ซึ่งส่งผลให้จังหวะฉิ่งตกห่างขึ้นหรือถี่ขึ้นตามไปด้วย
- [`<nathap>`](/th/v0_1/reference/elements/nathap/) อยู่ใน `<direction>` เช่นเดียวกัน และเป็นเมตาดาต้าในเงื่อนไขเดียวกันกับ `<chan>`

## การสอดคล้องมาตรฐาน

- `value` ต้องเป็นหนึ่งในห้าค่าที่ระบุ จับคู่ตรงตามที่เขียน ตัวตรวจสอบต้องปฏิเสธค่าอื่น รวมถึง `0.50` และ `.5`
