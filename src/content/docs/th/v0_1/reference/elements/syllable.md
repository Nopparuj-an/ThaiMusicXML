องค์ประกอบ `<syllable>` บรรจุพยางค์หนึ่งของเนื้อร้อง

## องค์ประกอบแม่

[`<measure>`](/th/v0_1/reference/elements/measure/) ในพาร์ตที่ [`type`](/th/v0_1/reference/elements/part/) เป็น `"lyric"`

## เนื้อหา

ข้อความ เขียนตามที่ควรอ่านออกเสียง พยางค์ถูกเลือกเป็นหน่วยเพราะภาษาไทยร้องทีละพยางค์ แต่ก็ไม่มีอะไรห้ามใส่คำสั้นทั้งคำลงไปแทนหนึ่งพยางค์ องค์ประกอบนี้ไม่ตรวจสอบว่าข้างในบรรจุอะไร

## ตัวอย่าง

```xml
<!-- สี่รายการในห้องสี่จังหวะ: แต่ละรายการอยู่ใต้จังหวะ -->
<measure number="4">
  <rest/>
  <rest/>
  <syllable>ละ</syllable>
  <syllable>หนอ</syllable>
</measure>
```

```xml
<!-- สามรายการในห้องสี่จังหวะ: กลุ่มจัดกลางในเซลล์ -->
<measure number="7">
  <rest/>
  <syllable>ดวง</syllable>
  <rest/>
  <syllable>เดือน</syllable>
</measure>
```

## การนับ

ห้องเนื้อเพลงมีรายการมากหรือน้อยเท่าที่คำต้องการ และจำนวนรายการนี่เองที่ตัดสินว่าจะจัดอิงจังหวะหรือไม่ ถ้าจำนวนตรงกับจำนวนจังหวะของห้อง แต่ละรายการจะอยู่ประจำจังหวะนั้น แต่ถ้าเขียนจำนวนอื่น กลุ่มคำจะถูกวางไว้ในเซลล์โดยไม่อิงจังหวะ

ทั้งสองแบบเป็นวิธีเขียนแนวร้องที่ใช้กันทั่วไป เพราะแนวร้องมักไม่แบ่งจังหวะเหมือนทำนองเครื่องดนตรีที่รองรับอยู่ พยางค์สามตัวในห้องสี่จังหวะบอกเพียงว่าคำเหล่านั้นเป็นของห้องนั้น โดยไม่ได้ยืนยันว่าแต่ละคำตกจังหวะไหน ดู [แถวเนื้อเพลง](/th/v0_1/reference/rendering/#แถวเนื้อเพลง)

นี่คือเหตุผลที่พาร์ตเนื้อเพลงเป็นพาร์ตเดียวที่ได้รับการยกเว้นจากกฎเรื่องจำนวนจังหวะ แต่ก็ยังใช้กริดบรรทัดและห้องร่วมกับพาร์ตอื่นทุกพาร์ตอยู่ดี ดู [`<section-ref>`](/th/v0_1/reference/elements/section-ref/#การสอดคล้องมาตรฐาน)

## เอื้อนและช่องว่าง

`<rest>` ในห้องเนื้อเพลงหมายความว่าไม่มีพยางค์ใหม่เริ่มขึ้นในจังหวะนั้น สระที่กำลังร้องอยู่ยังคงดำเนินต่อไป นั่นคือเอื้อน และมีความหมายเหมือนตัวหยุดในพาร์ตเครื่องดนตรีทุกประการ คือไม่มีการเริ่มเสียงใหม่ ไม่ใช่ความเงียบ

ตัวหยุดก็นับเป็นหนึ่งรายการด้วย ห้องที่มีพยางค์สามตัวกับตัวหยุดหนึ่งตัวจึงมีสี่รายการและจัดอิงจังหวะ ถ้าตัดตัวหยุดออก พยางค์สามตัวเดิมจะจัดกลางแทน ส่วนห้องที่ไม่มีลูกเลยคือห้องที่ไม่มีอะไรร้อง

ThaiMusicXML v0.1 ไม่มีเครื่องหมายเฉพาะสำหรับเอื้อนนอกเหนือจากนี้ ตัวหยุดเป็นตัวบอกตำแหน่งและระยะเวลาอยู่แล้ว ผู้เรียบเรียงที่ต้องการเขียนกำกับไว้บนหน้าโน้ตให้ใช้ [`<annotation>`](/th/v0_1/reference/elements/annotation/)

## การสอดคล้องมาตรฐาน

- `<syllable>` ใช้ได้เฉพาะภายใน `<measure>` ในพาร์ตที่ `type` เป็น `"lyric"`
- ห้องของพาร์ตเนื้อเพลงต้องมีเฉพาะ `<syllable>` และ `<rest>` `<note>`, `<group>`, `<bow>`, และ `<parenthesis>` ไม่ถูกต้อง
- จำนวนรายการในห้องเนื้อเพลงไม่ถูกจำกัด จะเท่ากับ มากกว่า น้อยกว่า หรือเป็นศูนย์เมื่อเทียบกับจำนวนจังหวะของห้องที่ตรงกันในพาร์ตอื่นก็ได้
- พาร์ตเนื้อเพลงยังต้องตรงกับพาร์ตอื่นเรื่องจำนวนบรรทัดและจำนวนห้องในแต่ละบรรทัด

## การแสดงผล

รายการจัดอิงจังหวะเมื่อจำนวนตรงกับจำนวนจังหวะ และจัดกลางเมื่อไม่ตรง ดู [แถวเนื้อเพลง](/th/v0_1/reference/rendering/#แถวเนื้อเพลง)
