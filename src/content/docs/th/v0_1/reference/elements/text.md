องค์ประกอบ `<text>` บรรจุข้อความจัดตำแหน่งหนึ่งช่วงภายใน [`<annotation>`](/th/v0_1/reference/elements/annotation/) หรือเครดิต

องค์ประกอบแม่แสดงผลเป็นบรรทัดเดียวที่มีตำแหน่งไม่เกินสาม ซ้าย กลาง ขวา แต่ละ `<text>` ครอบหนึ่งตำแหน่ง นี่คือสิ่งที่วางชื่อหน้าทับทางซ้ายโน้ตและผู้ประพันธ์ทางขวาบรรทัดเดียวกัน

## องค์ประกอบแม่

- [`<annotation>`](/th/v0_1/reference/elements/annotation/)
- [`<composer>`](/th/v0_1/reference/elements/composer/)
- [`<lyricist>`](/th/v0_1/reference/elements/lyricist/)
- [`<arranger>`](/th/v0_1/reference/elements/arranger/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| --------- | -------- | ----------- | ---------------------------------------------- |
| `align` | ใช่ | ค่าอีนัม | `"left"`, `"center"`, หรือ `"right"` |

`align` จำเป็น `<text>` มีไว้บอกว่าข้อความอยู่ที่ใด องค์ประกอบแม่ที่ต้องการช่วงเดียวในตำแหน่งเริ่มต้นเขียนข้อความธรรมดาแทน

## เนื้อหา

ข้อความเท่านั้น `<text>` ไม่รับลูก

ข้อความพิมพ์ตามที่เขียน ไม่มีสิ่งใดเพิ่มหน้า ต่อท้าย หรือสร้างรอบ นี่คือเหตุผลที่เครดิต `ผู้ประพันธ์ : พระประดิษฐไพเราะ` เป็นเครดิตที่ผู้เรียบเรียงพิมพ์ป้ายเป็นส่วนหนึ่งของสตริง ดู [แถบหัวเรื่อง](/th/v0_1/reference/rendering/#แถบหัวเรื่อง)

## ตัวอย่าง

```xml
<annotation>
  <text align="left">ท่อน 1</text>
  <text align="center">Lao Duang Duen</text>
  <text align="right">หน้า 1</text>
</annotation>
```

```xml
<composer>
  <text align="right">ผู้ประพันธ์ : พระประดิษฐไพเราะ</text>
</composer>
```

## สามตำแหน่ง ไม่ใช่สามคอลัมน์

ลูก `<text>` ขององค์ประกอบแม่เป็นสามตำแหน่งบนบรรทัดเดียว ไม่ใช่ข้อความที่วางติดกัน วางอิสระ การละตำแหน่งกลางไม่ขยับอีกสอง ลำดับในเอกสารไม่กระทบตำแหน่ง

ข้อความยาวเป็นปัญหาของผู้เรียบเรียงไม่ใช่ตัวแสดงผล ไม่มีสิ่งใดจัดใหม่หรือตัด `<text>` ที่ชนกับเพื่อนบ้าน

## การอ่านเป็นเมตาดาต้า

เครื่องมือที่ดึงเครดิตออกจากไฟล์เป็นสตริงต่อลูก `<text>` จากซ้ายไปขวา ตามลำดับ `align` ไม่ใช่ลำดับเอกสาร `align="left"` แล้ว `center` แล้ว `right`

## การสอดคล้องมาตรฐาน

- `align` จำเป็น ต้องเป็น `"left"`, `"center"`, หรือ `"right"` ตัวตรวจสอบต้องปฏิเสธค่าอื่น
- องค์ประกอบแม่อาจมี `<text>` ไม่เกินหนึ่งตัวต่อค่า `align`
- `<text>` ต้องมีเฉพาะข้อความ ลูกไม่ถูกต้อง
- เมื่อองค์ประกอบแม่มีลูก `<text>` ลูกเหล่านั้นเป็นเนื้อหา ข้อความอื่นข้าง ๆ ถูกละเลย ตัวตรวจสอบควรแจ้งเตือนเมื่อข้อความที่ถูกละเลยไม่ใช่ช่องว่างล้วน ดู [`<annotation>`](/th/v0_1/reference/elements/annotation/#การสอดคล้องมาตรฐาน)

## การแสดงผล

สามตำแหน่งแสดงผลบนบรรทัดเดียว ในแถบหัวเรื่องหรือระหว่างบล็อกท่อน ดู [หมายเหตุประกอบ](/th/v0_1/reference/rendering/#หมายเหตุประกอบ) และ [แถบหัวเรื่อง](/th/v0_1/reference/rendering/#แถบหัวเรื่อง)
