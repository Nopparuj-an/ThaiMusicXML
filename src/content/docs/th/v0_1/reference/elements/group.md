องค์ประกอบ `<group>` แบ่งจังหวะเดียวเป็นสองส่วนขึ้นไปเท่า ๆ กัน สำหรับห้องที่อัดโน้ตมากกว่าปกติในจังหวะเดียว

## องค์ประกอบแม่

[`<measure>`](/th/v0_1/reference/elements/measure/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| --------- | -------- | ------- | --------------------------------------------- |
| `link`    | ไม่ | บูลีน | วาดเส้นโค้งระบุว่ากลุ่มเป็นท่าทางเดียว เข้าถึงแถวอื่นของเครื่องดนตรีถ้ามี ดู [การสอดคล้องมาตรฐาน](#การสอดคล้องมาตรฐาน) ด้านล่าง |

## ลูก

ลำดับของ [`<note>`](/th/v0_1/reference/elements/note/) และ [`<rest>`](/th/v0_1/reference/elements/rest/) สองตัวขึ้นไป ลำดับใดก็ได้ อาจแทรก [`<bow>`](/th/v0_1/reference/elements/bow/) และ [`<parenthesis>`](/th/v0_1/reference/elements/parenthesis/)

## ความหมาย

`<group>` ใช้หนึ่งจังหวะพอดี ช่วงเวลาเดียวกับ `<note>` หรือ `<rest>` เดี่ยวที่ตำแหน่งเดียวกันใน `<measure>` จังหวะนั้นแบ่งเท่า ๆ กันในลูก `<note>` และ `<rest>` ของกลุ่ม: สองลูกได้คนละครึ่งจังหวะ สามลูกได้คนละหนึ่งในสาม เป็นต้น

### ตำแหน่งที่ลูกตก

จังหวะเกิดในช่องสุดท้าย ลูกสุดท้ายของกลุ่มจึงตกบนจังหวะ ส่วนตัวก่อนหน้าถอยหลังจากจุดนั้นอย่างสม่ำเสมอ

นี่คือจุดที่การแบ่งย่อยของไทยแยกจากตะวันตก ควรทำความเข้าใจให้ชัด ลอง `ด ร ม ซ` เทียบกับ `ด (ร ม) ซ ล` ตัว ม ของกลุ่มตกที่จังหวะที่สอง พร้อมกับตัว ร ของเวอร์ชันธรรมดา ส่วนตัว ร ของกลุ่มดังอยู่ระหว่างจังหวะแรกกับที่สอง การอ่านแบบตะวันตกจะวางตัว ร ไว้บนจังหวะแล้วให้ ม ตามมา

ทำเครื่องหมายโน้ตที่ตกจังหวะเป็น `X` และโน้ตระหว่างจังหวะเป็น `O`:

```
| -  -  - (ม ร ด) |    →    | -  -  - (O O X) |
| -  ร  -  ม      |    →    | -  X  -  X      |
| (ด ร) ม (ซ ล ท) (ดํ รํ) |    →    | (O X) X (O O X) (O X) |
```

`<note>` เปล่าเป็น `X` เสมอ: คือจังหวะ เฉพาะกลุ่มเท่านั้นที่สร้าง `O` และเฉพาะลูกที่ไม่ใช่ตัวสุดท้าย

### ทำไมกลุ่มออกจากห้องไม่ได้

จังหวะเป็นเจ้าของช่วงเวลา *ที่จบ* ที่จุดตก ไม่ใช่เริ่มจากจุดตก เขียน `d` เป็นความยาวหนึ่งช่อง จังหวะ `n` ของห้องมาถึง `n·d` จากขอบห้อง กลุ่ม `k` ลูกในจังหวะ `n` ดังที่ `n·d − (k−1)d/k` ถึง `n·d`

ลูกแรกจึงตก `(k−1)/k` ของจังหวะก่อน และเนื่องจาก `(k−1)/k` น้อยกว่า `1` เสมอ ตำแหน่งนั้นอยู่ภายในจังหวะ `n` เสมอ กลุ่มไม่เคยเข้าถึงจังหวะก่อนหน้า และไม่เคยข้ามขอบเขต `<measure>` หรือ `<line>` ไม่มีสิ่งใดบังคับ คณิตศาสตร์ไม่อนุญาต

ดู [จังหวะยึดด้านขวา](/th/v0_1/reference/rendering/#จังหวะยึดด้านขวา) สำหรับวิธีวางสัญลักษณ์บนหน้า และ [`<bpm>`](/th/v0_1/reference/elements/bpm/#การเดินช่อง) สำหรับการเล่น

`<bow>` และ `<parenthesis>` ปรากฏภายใน `<group>` ข้างโน้ตและตัวหยุดได้ ไม่มีความยาวและไม่นับรวมการแบ่ง กลุ่มที่มีลูก `<note>` สองตัวและ `<bow>` หนึ่งตัวยังแบ่งจังหวะเป็นสองไม่ใช่สาม ช่วงที่เปิดหรือปิดโดยตัวเหล่านี้ข้ามขอบเขต `<group>` ได้ เหมือนที่ข้ามขอบเขต `<measure>` และ `<line>` อยู่แล้ว

`link` ระบุว่ากลุ่มเป็นท่าทางเชื่อมต่อและขอเส้นโค้ง เป็นคำแนะนำการแสดงผลไม่มีผลต่อการเล่นหรือจังหวะ เพราะการแบ่งย่อยของกลุ่มอธิบายจังหวะอยู่แล้ว

เส้นโค้งไปที่ใดขึ้นอยู่กับเครื่องดนตรี บนเครื่องที่โน้ตข้ามหลายแถว (ดูแอตทริบิวต์ `stack` ของ [`<part>`](/th/v0_1/reference/elements/part/)) เส้นโค้งไปยังสิ่งที่แถวอื่นเล่นบนจังหวะเดียวกัน ระบุว่าแถวเป็นของท่าทางเดียว บนเครื่องดนตรีแถวเดียวไม่มีแถวอื่น เส้นโค้งอยู่เหนือโน้ตของกลุ่มเอง

กรณีที่สองทำให้แอตทริบิวต์มีประโยชน์บนโน้ตเดี่ยวที่เพลงไทยส่วนใหญ่เขียน กลุ่มแสดงโดยโน้ตชิดกันเท่านั้น ในห้องที่แน่นช่องว่างนั้นมีพื้นที่ทำงานน้อย `link` จึงเป็นวิธีที่ผู้เรียบเรียงบอกว่ากลุ่มต้องไม่คลุมเครือ

บนเครื่องสองแถวที่ออกแบบไว้ มีแถวอื่นหนึ่งแถวและเส้นโค้งหนึ่งเส้น บน stack สามแถวเข้าถึงทุกแถว ซึ่งไกลสุดที่บูลีนทำได้ กลุ่มที่ต้องเข้าถึงแถวเฉพาะหนึ่งและไม่อีกแถวไม่สามารถระบุได้ใน v0.1

## ตัวอย่าง

```xml
<!-- จังหวะที่ 2 แบ่งเป็นโน้ตตัวที่แปดสองตัว -->
<measure number="1">
  <note pitch="ด"/>
  <group>
    <note pitch="ร"/>
    <note pitch="ม"/>
  </group>
  <note pitch="ซ"/>
  <note pitch="ล"/>
</measure>
```

```xml
<!-- จังหวะแบ่งเป็นสาม -->
<group>
  <note pitch="ด"/>
  <note pitch="ร"/>
  <note pitch="ม"/>
</group>
```

## การสอดคล้องมาตรฐาน

- `<group>` ต้องมีลูก `<note>` หรือ `<rest>` อย่างน้อยสอง
- `<group>` ต้องไม่มี `<group>` ซ้อน การแบ่งย่อยใน ThaiMusicXML v0.1 ลึกหนึ่งชั้น
- `<bow>` และ `<parenthesis>` ภายใน `<group>` ไม่นับรวมการแบ่งเท่าของจังหวะ
- `link` ใช้ได้กับ `<group>` ใดก็ได้ เมื่อ `<part>` ที่ครอบไม่มี `stack` เส้นโค้งทำเครื่องหมายโน้ตของกลุ่มเองแทนที่จะเข้าถึงแถวอื่น
- เมื่อ `<part>` มี `stack` แถวอื่นอย่างน้อยหนึ่งต้องเป็นพาร์ตโน้ต หมายถึง `type="pitched"` หรือ `type="unpitched"` [พาร์ตเนื้อเพลง](/th/v0_1/reference/elements/part/#ประเภทพาร์ต) มี `stack` ได้ แต่ห้องเนื้อเพลงมีคำไม่ใช่จังหวะ จึงไม่มีตำแหน่งให้ตัวเชื่อมเข้าถึง `link` ที่ stack ไม่มีแถวโน้ตอื่นไม่ถูกต้อง
- ข้ามแถว `link` อธิบายการเชื่อมต่อ จึงประกาศฝั่งเดียว การทำเครื่องหมายกลุ่มในแถวบนเป็นธรรมเนียม
- `link` ชี้ไปยังสิ่งที่แถวอื่นของ stack เล่นที่ตำแหน่งกลุ่มนี้ เพราะทุกพาร์ตตรงกันเรื่องจำนวนจังหวะในห้อง (ดู [`<section-ref>`](/th/v0_1/reference/elements/section-ref/#การสอดคล้องมาตรฐาน)) ตำแหน่งนั้นนิยามเสมอ แถวอื่นอาจมี `<note>` เปล่า `<rest>` หรือ `<group>` ของตัวเอง
