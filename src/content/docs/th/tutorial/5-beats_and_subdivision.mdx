[โน้ต ตัวหยุด และ octave](/th/tutorial/4-notes_and_octaves/) แสดงให้เห็นว่าโน้ตและตัวหยุดทุกตัวกินเวลาหนึ่งจังหวะ หน้านี้แนะนำองค์ประกอบ `<group>` ซึ่งแบ่งจังหวะเดียวออกเป็นส่วนเท่า ๆ กัน และเป็นแนวคิดที่เป็นของ ThaiMusicXML มากที่สุด

ตัวอย่างในหน้านี้มาจากเพลงแขกบรเทศ ซึ่งมีการแบ่งย่อยหลากหลายกว่าลาวดวงเดือน

## กลุ่มคืออะไร

`<group>` กินเวลาหนึ่งจังหวะพอดี เท่ากับ `<note>` หรือ `<rest>` ตัวเดียว องค์ประกอบลูกของมันแบ่งจังหวะนั้นกันเท่า ๆ กัน ลูกสองตัวได้ตัวละครึ่งจังหวะ ลูกสามตัวได้ตัวละหนึ่งในสาม และเป็นเช่นนี้ไปเรื่อย ๆ

```xml
<!-- จังหวะ 3 แบ่งเป็นสองส่วน -->
<measure number="1">
  <note pitch="ด"/>
  <note pitch="ร"/>
  <group>
    <note pitch="ม"/>
    <note pitch="ซ"/>
  </group>
  <note pitch="ล"/>
</measure>
```

ห้องนี้มีสี่จังหวะ `<group>` ที่จังหวะ 3 มีโน้ตสองตัว แต่ละตัวจึงได้ครึ่งจังหวะ ส่วนอีกสามจังหวะมีจังหวะละหนึ่งโน้ต

กลุ่มต้องมีลูกที่เป็น `<note>` หรือ `<rest>` อย่างน้อยสองตัว และซ้อนกันไม่ได้ v1.0 แบ่งย่อยได้ลึกชั้นเดียว

## ลูกตกตรงไหน

จังหวะมาถึงที่ช่องสุดท้ายของมัน (ดู [แบบจำลองโน้ตเพลง](/th/tutorial/3-the_score_model/)) ลูกตัวสุดท้ายของกลุ่มจึงเป็นตัวที่ลงบนจังหวะ ส่วนตัวที่มาก่อนไล่เรียงถอยหลังออกมาจากจุดนั้น

ตรงนี้คือจุดที่การแบ่งย่อยแบบไทยแยกทางกับแบบสากล ในโน้ตสากล โน้ตเขบ็ตสองตัววางตัวแรกไว้บนจังหวะแล้วให้ตัวที่สองตามมา ส่วนใน ThaiMusicXML ตัวที่สองอยู่บนจังหวะ และตัวแรกเป็นตัวนำเข้าหาจังหวะนั้น

ถ้าใช้ `X` แทนโน้ตที่ลงบนจังหวะ และ `O` แทนโน้ตที่อยู่ระหว่างจังหวะ:

```
โน้ตธรรมดา:   | - ร  -  ม      | →  | -  X  -  X  |
กลุ่มสองตัว:   | - (ร ม) - ซ   | →  | - (O X) - X |
กลุ่มสามตัว:  | -  -  - (ด ร ม)| →  | -  -  - (O O X) |
```

`<note>` ธรรมดาเป็น `X` เสมอ เพราะมันคือตัวจังหวะ มีแต่กลุ่มเท่านั้นที่ทำให้เกิด `O` และเกิดเฉพาะกับลูกที่ไม่ใช่ตัวสุดท้าย

## ทำไมกลุ่มข้ามขอบเขตไม่ได้

กลุ่มกินเวลาหนึ่งจังหวะพอดี ลูกของมันแบ่งจังหวะเดียวนั้นกันเอง ต่อให้เป็นกลุ่มสามหรือสี่ตัวก็ยังอยู่ในช่วงเวลาเท่ากับโน้ตธรรมดาตัวเดียว ในเมื่อกลุ่มไม่เคยกินเกินหนึ่งจังหวะ มันจึงล้นเข้าไปในจังหวะก่อนหน้าไม่ได้ และข้ามขอบ `<measure>` หรือ `<line>` ไม่ได้ด้วย

## กลุ่มที่มีตัวหยุด

กลุ่มผสมโน้ตกับตัวหยุดได้ ตัวอย่างจากแขกบรเทศ ฆ้องวงใหญ่ R ท่อน 2 ห้อง 3:

```xml
<group>
  <rest/>
  <note pitch="ซ"/>
  <note pitch="ล"/>
</group>
```

นี่คือกลุ่มสามตัว ตัวหยุดกินหนึ่งในสามแรกของจังหวะ ซ กินหนึ่งในสามถัดมา และ ล เป็นตัวที่ลงบนจังหวะพอดี

## กลุ่มอยู่ร่วมกับโน้ตธรรมดา

ห้องหนึ่งผสมโน้ตธรรมดากับกลุ่มได้ จากพาร์ตเดียวกัน ห้อง 6:

```xml
<note pitch="ดํ"/>
<rest/><rest/>
<group>
  <note pitch="รํ"/>
  <note pitch="มํ"/>
</group>
```

สี่จังหวะ: ดํ อยู่จังหวะ 1 ตัวหยุดสองตัวอยู่จังหวะ 2 กับ 3 และกลุ่มสองตัวอยู่จังหวะ 4 โน้ตสองตัวในกลุ่มได้ตัวละครึ่งจังหวะ โดยมี มํ เป็นตัวที่ลงบนจังหวะ

## Link: การกำกับท่าทาง

กลุ่มบอกว่าจังหวะแบ่งอย่างไร แต่ไม่ได้บอกว่าโน้ตเหล่านั้นอยู่ด้วยกันเป็นการเคลื่อนมือครั้งเดียว ถ้าต้องการบอกเช่นนั้น ให้เขียนช่วง [`<link>`](/th/reference/elements/link/) ครอบไว้:

```xml
<note pitch="ด"/>
<link type="start"/>
<group>
  <note pitch="ร"/>
  <note pitch="ม"/>
</group>
<link type="stop"/>
<note pitch="ซ"/>
```

เส้นโค้งจะขึ้นเหนือ ร กับ ม โดยไม่เปลี่ยนการเล่นเลย เพราะการแบ่งย่อยของกลุ่มอธิบายจังหวะไว้อยู่แล้ว สิ่งที่มันเพิ่มเข้ามาคือความชัดเจน เนื่องจากปกติกลุ่มแสดงตัวด้วยการที่โน้ตชิดกันเท่านั้น และในห้องที่แน่น ระยะชิดนั้นแทบไม่เหลือที่ให้เห็น

เพราะ `<link>` เป็นตัวกำกับที่มาเป็นคู่ ไม่ใช่สิ่งที่กลุ่มถือไว้เอง ช่วงจึงวิ่งเลยจังหวะที่มันเปิดไว้ได้:

```xml
<note pitch="ด"/>
<link type="start"/>
<group><note pitch="ร"/><note pitch="ม"/></group>
<group><note pitch="ซ"/><note pitch="ล"/></group>
<link type="stop"/>
<note pitch="ท"/>
```

เส้นโค้งเส้นเดียวคลุมโน้ตสี่ตัวสองจังหวะ นี่คือรูปร่างปกติของสะบัดในเพลงไทย และเป็นเหตุผลที่เครื่องหมายนี้เป็นองค์ประกอบแทนที่จะเป็นแอตทริบิวต์บน `<group>` เพราะกลุ่มคือหนึ่งจังหวะพอดี ส่วนท่าทางมักไม่ได้ลงตัวเท่านั้น

### เข้าถึงแถวอื่น

เมื่อ `<part>` ที่ครอบอยู่มีแอตทริบิวต์ `stack` คือเครื่องดนตรีนั้นเขียนโน้ตข้ามหลายแถว เส้นโค้งจะเข้าถึงแถวอื่นด้วย

จากแขกบรเทศ ท่อน 2 ห้อง 3 ทั้งสองแถวของฆ้องวงใหญ่:

ฆ้องวงใหญ่ R:

```xml
<link type="start"/>
<group>
  <rest/>
  <note pitch="ซ"/>
  <note pitch="ล"/>
</group>
<link type="stop"/>
```

ฆ้องวงใหญ่ L:

```xml
<group>
  <note pitch="ฟ"/>
  <rest/><rest/>
</group>
```

เครื่องดนตรีทำเสียง ฟ ซ ล ตลอดจังหวะนั้น เส้นโค้งจึงวิ่งจาก ฟ ในแถว L ไปหา ล ในแถว R ไม่มีแถวไหนถือปลายทั้งสองข้างไว้เอง บนเครื่องดนตรีที่ซ้อนแถว ตรงนี้คือสิ่งที่บอกผู้เล่นว่าสองแถวนั้นเป็นท่าทางเดียวกัน

ประกาศไว้ฝั่งเดียวก็พอ ช่วงในแถวบนอธิบายการเชื่อมต่อไว้แล้ว ไม่ต้องไปกำกับสิ่งที่มันเข้าถึงซ้ำอีก ตัวกำกับทั้งคู่ต้องอยู่ในพาร์ตเดียวกันเสมอ จะเปิดในแถวหนึ่งแล้วไปปิดในอีกแถวไม่ได้

## สองพาร์ตแบ่งย่อยต่างกัน

พาร์ตต่างกันแบ่งจังหวะเดียวกันคนละแบบได้ เครื่องดนตรีหนึ่งอาจเล่นโน้ตธรรมดาขณะที่อีกเครื่องเล่นกลุ่มสามตัว กริดก็ยังตรงกันอยู่ดี เพราะตำแหน่งจังหวะเป็นของที่ทุกพาร์ตใช้ร่วมกัน

```xml
<!-- พาร์ต A: จังหวะ 2 เป็นโน้ตธรรมดา -->
<note pitch="ด"/><note pitch="ร"/><note pitch="ม"/><note pitch="ซ"/>

<!-- พาร์ต B: จังหวะ 2 เป็นกลุ่มสามตัว -->
<note pitch="ด"/><group><note pitch="ร"/><note pitch="ม"/><note pitch="ซ"/></group><note pitch="ม"/><note pitch="ล"/>
```

ทั้งสองห้องมีสี่จังหวะ ร ของพาร์ต A อยู่บนจังหวะ 2 ส่วนกลุ่มของพาร์ต B แบ่งจังหวะ 2 ออกเป็นสามส่วน โดย ซ ลงบนจังหวะ แล้ว ร กับ ม ไล่ถอยหลังออกมาจากจุดนั้น จังหวะจึงตรงกันแม้โน้ตจะไม่ตรงกัน
