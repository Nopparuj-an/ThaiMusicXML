ถึงตรงนี้คุณมีโน้ตเพลงแล้ว เข้าใจองค์ประกอบแล้ว และรู้แล้วว่าแบบจำลองทำงานอย่างไร หน้านี้ว่าด้วยวิธีตรวจงานของตัวเอง และแหล่งเรียนรู้ต่อจากนี้

## การตรวจสอบ Schema

ThaiMusicXML มี Schema RELAX NG อยู่ที่ `public/schema/thaimusicxml-1.x.rng` จะตรวจไฟล์กับ Schema ด้วยตัวตรวจ RELAX NG ตัวไหนก็ได้ ตัวอย่างนี้ใช้ `xmllint`:

```bash
xmllint --noout --relaxng public/schema/thaimusicxml-1.x.rng your-file.txml
```

Schema ตรวจเรื่องโครงสร้าง ว่าองค์ประกอบไหนอยู่ตรงไหนได้ แอตทริบิวต์ไหนใช้ได้ และค่าแบบไหนที่รับ แต่ไม่ได้ตรวจกฎทางดนตรี

## การตรวจคอร์ปัส

กฎทางดนตรีที่ Schema เขียนไว้ไม่ได้นั้นอยู่ใน `scripts/check-corpus.mjs` สคริปต์นี้รันกับไฟล์ `.txml` ทุกไฟล์ใน `public/corpus/valid/` และตรวจว่า:

- ห้องที่ตรงกันระหว่างพาร์ตมีจำนวนจังหวะเท่ากัน
- หมายเลขบรรทัดและหมายเลขห้องเรียงตามลำดับ
- `<group>` มีลูกอย่างน้อยสองตัว
- ค่า `<ending pass>` สอดคล้องกัน

รันด้วย:

```bash
npm run check:corpus
```

ถ้ากำลังจะส่งงานถอดโน้ต สคริปต์นี้จะตรวจไฟล์ของคุณด้วยกฎชุดเดียวกับที่คอร์ปัสใช้

## Playground

[Playground](/th/playground/) ให้แก้ไขและแสดงผลไฟล์ ThaiMusicXML ได้ในเบราว์เซอร์ วาง XML ลงไป ดูโน้ตเพลงอัปเดตทันที แล้วส่ง URL ให้คนอื่นดูได้

Playground ใช้ตัวแสดงผลตัวเดียวกับที่เอกสารชุดนี้ใช้ สิ่งที่เห็นใน Playground จึงตรงกับรูปในเอกสาร

## กรณีที่ตัวประมวลผลต้องเตือน

บางกรณีตัวประมวลผลที่สอดคล้องมาตรฐานต้องเตือน แทนที่จะปฏิเสธไฟล์ไปเลย:

- ห้องที่ไม่มีโน้ต ตัวหยุด หรือกลุ่ม (จำนวนจังหวะเป็นศูนย์)
- ห้องที่ตรงกันระหว่างพาร์ตมีจำนวนจังหวะต่างกัน
- `<group>` ที่ข้ามขอบเขตห้อง
- ค่า `<ending pass>` ข้ามรอบหรือซ้ำรอบ

ทั้งหมดนี้เป็นคำเตือน ไม่ใช่ข้อผิดพลาด ไฟล์ยังโหลดได้ตามปกติ ตัวประมวลผลเพียงบอกว่ามีบางอย่างดูไม่ถูก เพื่อให้กลับไปแก้

## แหล่งเรียนรู้เพิ่มเติม

บทเรียนครอบคลุมองค์ประกอบหลักไปแล้ว ส่วนเอกสารอ้างอิงมีรายละเอียดมากกว่านั้น:

- [องค์ประกอบ](/th/reference/elements/): ทุกองค์ประกอบ พร้อมแอตทริบิวต์ ลูก และกฎการสอดคล้องมาตรฐาน
- [ตัวอย่าง](/th/reference/examples/): โน้ตเพลงฉบับสมบูรณ์ ทั้งลาวดวงเดือน แขกบรเทศ และเพลงอื่น ๆ
- [การสอดคล้องมาตรฐาน](/th/reference/conformance/): กฎที่เอกสารต้องเป็นไปตาม รวบรวมจากหน้าองค์ประกอบแต่ละหน้า
- [การแสดงผล](/th/reference/rendering/): วิธีจัดวางและแสดงโน้ตเพลง ซึ่งไม่ใช่ข้อบังคับ
- [แผนงาน](/th/updates/roadmap/): สิ่งที่วางแผนไว้สำหรับเวอร์ชันถัดไป

ถ้าจะส่งงานถอดโน้ต ให้ดูรูปแบบไฟล์ฉบับสมบูรณ์ได้ที่หน้าตัวอย่าง ตรวจด้วย Schema และการตรวจคอร์ปัส แล้วใช้ Playground ดูผลที่แสดงออกมาอีกที

:::note[เครื่องมือที่ครอบคลุม]
[Schema RELAX NG](/th/reference/conformance/), [การตรวจคอร์ปัส](/th/reference/conformance/), [Playground](/th/playground/)
:::
