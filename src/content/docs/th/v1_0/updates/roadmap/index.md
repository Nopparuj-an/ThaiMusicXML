## เวอร์ชัน v1.0 (ระยะพัฒนา)

**ThaiMusicXML v1.0** เป็นรุ่นแรก ขณะนี้กำลังจัดทำและพัฒนามาตรฐาน โดยเน้นแนวคิดหลักและฟังก์ชันพื้นฐาน

### ขอบเขต

- โครงสร้างหลักสำหรับการเขียนโน้ตดนตรีไทย (ระบบเสียง 7 เสียง, กริด 8 ห้อง, ระดับชั้น)
- รองรับองค์ประกอบพื้นฐาน: โน้ต, ตัวหยุด, ห้อง, บรรทัด, ท่อน, พาร์ต
- เนื้อร้องบนกริด ในรูปแบบพาร์ตเนื้อเพลงที่ประกอบด้วยองค์ประกอบ `<syllable>`

### สิ่งที่ยังไม่ครอบคลุมใน v1.0

ส่วนที่ขาดหายไปเหล่านี้เป็นที่ทราบแล้ว เลื่อนไปเวอร์ชันถัดไปแทนที่จะมองข้าม เอกสาร v1.0 สามารถบันทึกได้เฉพาะในรูปแบบข้อความ `<annotation>` เท่านั้น

- **หน้าทับและรูปแบบกลอง** [`<nathap>`](/en/v1_0/reference/elements/nathap/) ถูกระบุไว้ แต่ไม่ได้มีการใช้งานโดยตรง
- **เนื้อเพลงหลายบท** [พาร์ตเนื้อเพลง](/en/v1_0/reference/elements/part/#part-types) บรรจุเนื้อเพลงได้ชุดเดียว บทที่สองที่ใช้ทำนองเดียวกันต้องเขียนเป็นพาร์ตเนื้อเพลงที่สอง และไม่มีเครื่องหมายระบุว่าทั้งสองเป็นทางเลือกแทนกัน
- **เอื้อน** [`<rest>`](/en/v1_0/reference/elements/rest/) ในแถวเนื้อเพลงระบุตำแหน่งและระยะเวลาของเอื้อน ซึ่งเป็นขอบเขตสูงสุดที่ v1.0 ทำได้ ไม่มีเครื่องหมายระบุชื่อเอื้อนโดยตรง และไม่สามารถเขียนรูปแบบการร้องได้
- **การประดับเสียง** เทคนิคเช่น กรอ ไม่มีมาร์กอัปเฉพาะ [`<group>`](/th/v1_0/reference/elements/group/) ครอบคลุมการแบ่งย่อยจังหวะ ส่วนช่วง [`<link>`](/th/v1_0/reference/elements/link/) ทำเครื่องหมายว่าโน้ตชุดหนึ่งเป็นท่าทางเดียว ซึ่งใกล้เคียงที่สุดที่ v1.0 ระบุสะบัดได้ ทั้งสองไม่ได้บอกว่าเป็นเทคนิคใด
- **ระดับเสียงพร้อมกันภายในพาร์ตเดียว** `<note>` บรรจุระดับเสียงเดียว จึงไม่สามารถเขียนคู่แปดหรือช่วงเสียงที่คล้ายกันในบรรทัดเดียวได้ เครื่องดนตรีที่ต้องการมากกว่าหนึ่งบรรทัดจะแบ่งเป็น `stack` ของพาร์ตแทน
- **ทาง** [`<tuning>`](/en/v1_0/reference/elements/tuning/) กำหนดว่า ด มีระดับเสียงเท่าใด แต่ไม่มีองค์ประกอบสำหรับระบุทางที่เพลงเล่น
- **ทิศทางภายในท่อน** [`<direction>`](/th/v1_0/reference/elements/direction/) อยู่ใน `<structure>` ระหว่างท่อน จังหวะและชั้นจึงเปลี่ยนได้เฉพาะที่ขอบท่อน เพลงที่เร่งขึ้นในสองบรรทัดสุดท้ายต้องบอกไว้ใน [`<annotation>`](/th/v1_0/reference/elements/annotation/)
- **ความแปรผันของการเล่นรอบใดรอบหนึ่งในช่วงบรรทัดที่ซ้ำ** [`<ending>`](/th/v1_0/reference/elements/ending/) แปรผันรอบของ*ท่อน* คำว่าซ้ำแล้วเที่ยวสองลงจบอีกอย่างเหนือช่วง [`<line-repeat>`](/th/v1_0/reference/elements/line-repeat/) จึงเขียนตรง ๆ ไม่ได้ การเขียนบรรทัดชุดนั้นซ้ำอีกครั้งพร้อมความแปรผันสื่อดนตรีเดียวกัน โดยแลกกับวงเล็บซ้ำ

### ขั้นตอนถัดไป

- พัฒนาส่วนหลักและเพิ่มฟีเจอร์ต่อไป
- พัฒนาตัวตรวจสอบและตัวแปลงตามโครงสร้างหลัก
- พัฒนาตัวแสดงผล
- รวบรวมความคิดเห็นจากชุมชน
- เตรียมเปิดตัวเวอร์ชันถัดไป
