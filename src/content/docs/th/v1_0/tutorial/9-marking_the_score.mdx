[วงดนตรีและเครื่องดนตรีที่ซ้อนแถว](/th/v1_0/tutorial/7-ensembles_stacked/) เพิ่มพาร์ตหลายพาร์ตเข้ามาในโน้ตเพลง หน้านี้ว่าด้วยองค์ประกอบที่เปลี่ยนกริดเปล่า ๆ ให้กลายเป็นโน้ตเพลงที่พิมพ์ใช้ได้จริง ได้แก่ เครื่องหมายคันชัก ช่วงที่อ้างอิง หมายเหตุประกอบ และข้อมูลเมตา

## เครื่องหมายคันชัก

<Image src={bowSpans} width={200} alt="เครื่องหมายคันชัก" />

`<bow>` ทำเครื่องหมายจุดเริ่มต้นและจุดสิ้นสุดของการใช้คันชักบนเครื่องสาย ใช้ `type="start"` คู่กับ `type="stop"` และมีแอตทริบิวต์ `direction` (`in` หรือ `out`):

```xml
<bow type="start" direction="out"/><note pitch="ด"/><note pitch="ร"/><bow type="stop"/><note pitch="ม"/>
```

ช่วงนี้คลุม ด กับ ร ส่วน ม เล่นโดยไม่มีเครื่องหมายคันชัก ตัวอย่างจากซออู้ในท่อน 1:

```xml
<measure number="3">
  <rest/><bow type="start" direction="out"/><note pitch="ด"/><note pitch="ร"/><bow type="stop"/><note pitch="ม"/>
</measure>
```

เครื่องหมายคันชักไม่กินเวลา จึงไม่นับเป็นจังหวะ และข้ามขอบ `<group>`, `<measure>`, `<line>` ได้อย่างอิสระ ช่วงที่มีโน้ตตัวเดียวก็เขียนได้ คือโน้ตตัวนั้นมีทั้ง start และ stop คร่อมอยู่

## วงเล็บ

<Image src={parenthesis} width={200} alt="วงเล็บ" />

`<parenthesis>` กำกับว่าช่วงนั้นเป็นช่วงที่อ้างอิงไว้ ใส่ `dim="true"` เพิ่มเพื่อให้พิมพ์จางลง:

```xml
<parenthesis type="start" dim="true"/><note pitch="ด"/><note pitch="ร"/><note pitch="ด"/><note pitch="ล"/><parenthesis type="stop"/>
```

ตัวอย่างจากระนาดเอกในท่อน 2 ช่วงที่พิมพ์จางกินสองห้อง:

```xml
<measure number="1">
  <parenthesis type="start" dim="true"/><rest/><rest/><rest/><note pitch="ร"/>
</measure>
<measure number="2">
  <note pitch="ด"/><note pitch="ด"/><note pitch="ด"/><note pitch="ด"/><parenthesis type="stop"/>
</measure>
```

เครื่องหมายวงเล็บไม่กินเวลาและข้ามขอบได้อย่างอิสระเช่นเดียวกับเครื่องหมายคันชัก

## `<br>`: การเว้นบรรทัด

`<br>` เว้นช่องว่างแนวตั้งในโน้ตเพลงที่แสดงผลออกมา เป็นองค์ประกอบปิดตัวเองที่ไม่มีแอตทริบิวต์:

```xml
<structure>
  <br/>
  <annotation>เพลงลาวดำเนินเกวียน ...</annotation>
  <br/>
  <direction>...</direction>
</structure>
```

โน้ตเพลงหลักใช้ `<br>` คั่นระหว่างหมายเหตุประกอบกับบล็อก `<direction>` ใช้เท่าที่จำเป็นก็พอ เพราะโครงสร้างของกริดจัดระเบียบให้อยู่แล้ว

## หมายเหตุประกอบและการจัดตำแหน่ง

<Image src={annotations} width={600} alt="หมายเหตุประกอบและการจัดตำแหน่ง" />

`<annotation>` ใช้คู่กับ `<text align>` เพื่อกำหนดตำแหน่งข้อความในช่อง:

```xml
<annotation>
  <text align="left">ท่อน 1</text>
  <text align="center">Lao Duang Duen</text>
  <text align="right">หน้า 1</text>
</annotation>
```

ค่า `align` เป็น `left`, `center`, หรือ `right` ก็ได้ ส่วนข้อความธรรมดาในหมายเหตุประกอบจัดชิดซ้ายเป็นค่าตั้งต้น

หลักการออกแบบคือ อยากให้อะไรพิมพ์ออกมา ก็พิมพ์สิ่งนั้นเอง แอตทริบิวต์ `name` ของท่อนอยู่ในไฟล์เท่านั้น สิ่งที่ปรากฏบนหน้ากระดาษคือสิ่งที่ผู้เรียบเรียงใส่ไว้ใน `<annotation>` หรือในเครดิต

## เครดิตและข้อมูลอื่น ๆ

<Image src={credits} width={600} alt="เครดิตและข้อมูลอื่น ๆในส่วนหัว" />

`<header>` มีองค์ประกอบข้อมูลเมตาได้อีกหลายอย่าง:

```xml
<header>
  <title>ลาวดวงเดือน</title>
  <composer><text align="right">ทำนอง: พระเจ้าบรมวงศ์เธอ กรมหมื่นพิไชยมหินทโรดม</text></composer>
  <lyricist><text align="right">เนื้อร้อง: พระเจ้าบรมวงศ์เธอ กรมหมื่นพิไชยมหินทโรดม</text></lyricist>
  <arranger><text align="right">รวบรวมและดัดแปลงจากหลายแหล่ง</text></arranger>
  <tuning reference="khrueang-sai"/>
  <license>PUBLIC DOMAIN</license>
</header>
```

- `<lyricist>` ระบุผู้แต่งเนื้อร้อง
- `<arranger>` ระบุผู้ดัดแปลงหรือผู้ถอดโน้ต
- `<tuning>` บันทึกระบบเสียงที่ใช้ แอตทริบิวต์ `reference` ระบุชื่อมาตรฐานการตั้งเสียง
- `<license>` ระบุสัญญาอนุญาต

องค์ประกอบเหล่านี้เป็นข้อมูลเมตาสำหรับตัวไฟล์และเครื่องมือที่อ่านไฟล์ ส่วนจะพิมพ์ลงหน้ากระดาษหรือไม่ เป็นเรื่องของตัวแสดงผล

## หน้าทับ

`<nathap>` บันทึกว่าเพลงนี้วางอยู่บนหน้าทับใด เขียนไว้ใน `<direction>` และเป็นข้อมูลเมตาระดับเดียวกับ `<chan>`:

```xml
<nathap value="ลาว"/>
```

ข้อมูลนี้ส่งต่อไปยังเครื่องมือแก้ไขและเอนจินเล่นเสียง ไม่ได้ทำให้เกิดป้ายอะไรบนหน้ากระดาษ
