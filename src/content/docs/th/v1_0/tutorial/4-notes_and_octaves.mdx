## ตารางโน้ต

ThaiMusicXML ใช้ชื่อดีกรีระบบเสียงไทยเป็นชื่อโน้ต มีเจ็ดดีกรี แต่ละดีกรีมีการสะกดสามแบบ:

| ดีกรี | ตัวเลข | โรมัน | ไทย |
| ------ | ------- | --------- | ---- |
| 1      | 1       | D         | ด    |
| 2      | 2       | R         | ร    |
| 3      | 3       | M         | ม    |
| 4      | 4       | F         | ฟ    |
| 5      | 5       | S         | ซ    |
| 6      | 6       | L         | ล    |
| 7      | 7       | T         | ท    |

การสะกดทั้งสามแบบเป็นโน้ตเดียวกัน `pitch="1"`, `pitch="D"`, และ `pitch="ด"` ให้ผลลัพธ์เหมือนกัน ไฟล์หนึ่งเลือกการสะกดแบบใดแบบหนึ่งแล้วยึดตามนั้น

ตัวอักษรโรมันไม่แยกตัวเล็กตัวใหญ่ `d` กับ `D` เป็นดีกรีเดียวกัน ส่วนตัวเลขกับอักษรไทยมีเพียงรูปเดียว

## เครื่องหมาย octave

เจ็ดดีกรีครอบคลุมหนึ่ง octave เพื่อเข้าถึง octave ที่สูงกว่าหรือต่ำกว่า โน้ตไทยใช้ตัวปรับสองตัว:

| ตัวปรับ | ไทย | ผล            | ตัวอย่าง                    |
| -------- | ---- | ----------------- | -------------------------- |
| นิคหิต   | ํ    | ยกขึ้นหนึ่ง octave | ดํ คือ ด สูงขึ้นหนึ่ง octave      |
| พินทุ    | ฺ    | ลดลงหนึ่ง octave | ทฺ คือ ท ต่ำลงหนึ่ง octave    |

ตัวปรับติดกับการสะกดทั้งสามแบบ `1ํ`, `Dํ`, และ `ดํ` เป็นโน้ตเดียวกัน สูงกว่า ด หนึ่ง octave ซ้อนกันได้ `ดํํ` คือสูงขึ้นสอง octave แต่ในทางปฏิบัติ ส่วนใหญ่ไม่เกินสอง octave ในแต่ละทิศทาง

octave เริ่มต้น (ไม่มีตัวปรับ) คือระดับกลาง นิคหิตยกจากจุดนั้น พินทุลดลง

## octave ที่เกินกว่าการสะกดไทย

เมื่อโน้ตถึงระดับที่ตัวปรับไทยแสดงไม่ได้ชัดเจน แอตทริบิวต์ `octave` ให้ตัวเลขโดยตรง:

```xml
<note pitch="ด" octave="2"/>
<note pitch="D" octave="-2"/>
```

`octave="0"` คือระดับกลางเริ่มต้น ตัวเลขบวกขึ้น ตัวเลขลบลง แอตทริบิวต์นี้ใช้ได้กับการสะกดทุกแบบ

## ตัวหยุด

`<rest>` ใช้เวลาหนึ่งจังหวะเท่ากับ `<note>` หมายความว่าเครื่องดนตรีไม่ตีเสียงใหม่ในจังหวะนั้น ดังที่หน้า 3 อธิบาย เครื่องดนตรีไทยไม่มีเครื่องหมายการประคองเสียง ตัวหยุดจึงไม่ใช่ความเงียบ แต่เป็นการไม่ตี โน้ตที่ปล่อยให้ก้องอยู่ใต้ตัวหยุดคือเครื่องดนตรีทำงานตามปกติ

```xml
<rest/>
```

ตัวหยุดเป็นองค์ประกอบปิดตัวเองที่ไม่มีแอตทริบิวต์ ทุกจังหวะในห้องเป็น `<note>`, `<rest>`, หรือ `<group>`

## พาร์ตที่ไม่มีระดับเสียง

เครื่องดนตรีบางชิ้น เช่น ฉิ่ง ไม่เล่นโน้ตที่มีระดับเสียง ตั้ง `type="unpitched"` บน `<part>` หมายความว่าโน้ตใช้ `sound` แทน `pitch`:

```xml
<rest/><rest/><rest/><note sound="ฉิ่ง"/>
```

แอตทริบิวต์ `sound` รับข้อความใดก็ได้ ค่าเป็นเรื่องภายในพาร์ต ดังนั้น `<annotation>` ภายใน `<section-ref>` มักใช้บันทึกคำอธิบาย

จากไฟล์ลาวดวงเดือน พาร์ตฉิ่งในสองชั้น:

```xml
<line number="1">
  <measure number="1"><rest/><rest/><rest/><note sound="ฉิ่ง"/></measure>
  <measure number="2"><rest/><rest/><rest/><note sound="ฉับ"/></measure>
</line>
```

ในสองชั้น ฉิ่งตีหนึ่งครั้งต่อห้อง สลับฉิ่งกับฉับทุกห้อง ในชั้นเดียวรอบจะจบภายในห้องเดียว: `rest, ฉิ่ง, rest, ฉับ`

## แบบฝึกหัด: การสะกดโน้ต

ไฟล์ `public/corpus/valid/pitch-spellings.txml` ฝึกการสะกดทั้งสามแบบและตัวปรับทั้งสองตัวในบรรทัดเดียว:

```xml
<part-data part="P1">
  <section-ref section="s1">
    <line number="1">
      <measure number="1">
        <note pitch="1"/><note pitch="2"/><note pitch="3"/><note pitch="4"/>
      </measure>
      <measure number="2">
        <note pitch="S"/><note pitch="L"/><note pitch="t"/><note pitch="d"/>
      </measure>
      <measure number="3">
        <note pitch="ด"/><note pitch="ร"/><note pitch="ม"/><note pitch="ฟ"/>
      </measure>
      <measure number="4">
        <note pitch="ดํ"/><note pitch="ทฺ"/><note pitch="ด" octave="2"/><note pitch="D" octave="-2"/>
      </measure>
    </line>
  </section-ref>
</part-data>
```

ห้อง 1 ใช้ตัวเลข ห้อง 2 ใช้โรมัน ห้อง 3 ใช้อักษรไทย ห้อง 4 แสดงตัวปรับ: นิคหิต (ดํ), พินทุ (ทฺ), และแอตทริบิวต์ `octave`
