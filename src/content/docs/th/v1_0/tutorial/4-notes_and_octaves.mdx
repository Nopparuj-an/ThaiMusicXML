## ตารางระดับเสียง

ThaiMusicXML ใช้ชื่อระดับเสียงของไทยเป็นชื่อโน้ต ระดับเสียงมีเจ็ดเสียง และแต่ละเสียงสะกดได้สามแบบ:

| เสียงที่ | ตัวเลข | โรมัน | ไทย |
| ------ | ------- | --------- | ---- |
| 1      | 1       | D         | ด    |
| 2      | 2       | R         | ร    |
| 3      | 3       | M         | ม    |
| 4      | 4       | F         | ฟ    |
| 5      | 5       | S         | ซ    |
| 6      | 6       | L         | ล    |
| 7      | 7       | T         | ท    |

การสะกดทั้งสามแบบหมายถึงโน้ตตัวเดียวกัน `pitch="1"`, `pitch="D"`, และ `pitch="ด"` ให้ผลเหมือนกันทุกประการ ไฟล์หนึ่งควรเลือกแบบใดแบบหนึ่งแล้วใช้แบบนั้นตลอด

อักษรโรมันไม่แยกตัวพิมพ์เล็กตัวพิมพ์ใหญ่ `d` กับ `D` เป็นเสียงเดียวกัน ส่วนตัวเลขและอักษรไทยมีรูปเดียวอยู่แล้ว

## เครื่องหมาย octave

เจ็ดเสียงนี้กินพื้นที่หนึ่ง octave ถ้าจะขึ้นไป octave ที่สูงกว่าหรือลงไปที่ต่ำกว่า โน้ตไทยใช้เครื่องหมายกำกับสองตัว:

| เครื่องหมาย | ไทย | ผล            | ตัวอย่าง                    |
| -------- | ---- | ----------------- | -------------------------- |
| นิคหิต   | ํ    | ยกขึ้นหนึ่ง octave | ดํ คือ ด สูงขึ้นหนึ่ง octave      |
| พินทุ    | ฺ    | ลดลงหนึ่ง octave | ทฺ คือ ท ต่ำลงหนึ่ง octave    |

เครื่องหมายทั้งสองใช้กับการสะกดได้ทั้งสามแบบ `1ํ`, `Dํ`, และ `ดํ` จึงหมายถึงโน้ตตัวเดียวกัน คือ ด ที่สูงขึ้นหนึ่ง octave เครื่องหมายเหล่านี้ซ้อนกันไม่ได้ ระดับเสียงหนึ่งมีเครื่องหมายได้ไม่เกินหนึ่งตัว ถ้าจะขึ้นหรือลงเกินหนึ่ง octave ให้ใช้แอตทริบิวต์ `octave` ข้างล่างแทนการเติมเครื่องหมายตัวที่สอง

octave ตั้งต้นคือช่วงเสียงกลาง ซึ่งก็คือเมื่อไม่มีเครื่องหมายกำกับเลย นิคหิตยกขึ้นจากตรงนั้น ส่วนพินทุลดลง

## octave ที่เกินกว่าการสะกดไทย

เมื่อดนตรีไปถึงช่วงเสียงที่เครื่องหมายไทยเขียนได้ไม่ชัด ให้ระบุเป็นตัวเลขตรง ๆ ด้วยแอตทริบิวต์ `octave`:

```xml
<note pitch="ด" octave="2"/>
<note pitch="D" octave="-2"/>
```

`octave="0"` คือช่วงเสียงกลางตั้งต้น เลขบวกคือสูงขึ้น เลขลบคือต่ำลง แอตทริบิวต์นี้ใช้ได้กับการสะกดทุกแบบ

## ตัวหยุด

`<rest>` กินเวลาหนึ่งจังหวะเท่ากับ `<note>` และหมายความว่าเครื่องดนตรีไม่ได้ตีเสียงใหม่ในจังหวะนั้น อย่างที่หน้า 3 อธิบายไว้ เครื่องดนตรีไทยไม่มีการลากเสียงที่เขียนกำกับไว้ ตัวหยุดจึงไม่ใช่ความเงียบ แต่คือการไม่ตี เสียงที่ยังก้องอยู่ใต้ตัวหยุดเป็นเรื่องปกติของตัวเครื่องดนตรีเอง

```xml
<rest/>
```

ตัวหยุดเป็นองค์ประกอบปิดตัวเองที่ไม่มีแอตทริบิวต์ ทุกจังหวะในห้องต้องเป็น `<note>`, `<rest>`, หรือ `<group>` อย่างใดอย่างหนึ่ง

## พาร์ตที่ไม่มีระดับเสียง

เครื่องดนตรีบางชิ้น เช่น ฉิ่ง ไม่ได้ตีเป็นระดับเสียง การตั้ง `type="unpitched"` บน `<part>` หมายความว่าโน้ตของพาร์ตนั้นใช้ `sound` แทน `pitch`:

```xml
<rest/><rest/><rest/><note sound="ฉิ่ง"/>
```

แอตทริบิวต์ `sound` รับข้อความอะไรก็ได้ ความหมายของค่าเป็นเรื่องภายในพาร์ตนั้นเอง จึงนิยมเขียน `<annotation>` ไว้ใน `<section-ref>` เพื่ออธิบายว่าแต่ละค่าหมายถึงอะไร

จากไฟล์ลาวดวงเดือน พาร์ตฉิ่งในสองชั้น:

```xml
<line number="1">
  <measure number="1"><rest/><rest/><rest/><note sound="ฉิ่ง"/></measure>
  <measure number="2"><rest/><rest/><rest/><note sound="ฉับ"/></measure>
</line>
```

ในสองชั้น ฉิ่งตีห้องละครั้ง สลับฉิ่งกับฉับไปทีละห้อง ส่วนในชั้นเดียว รอบหนึ่งจบภายในห้องเดียว คือ `rest, ฉิ่ง, rest, ฉับ`

## แบบฝึกหัด: การสะกดโน้ต

ไฟล์ `public/corpus/valid/pitch-spellings.txml` รวมการสะกดทั้งสามแบบและเครื่องหมายทั้งสองตัวไว้ในบรรทัดเดียว:

```xml
<part-data part="P1">
  <section-ref section="s1">
    <line number="1">
      <measure number="1">
        <note pitch="1"/><note pitch="2"/><note pitch="3"/><note pitch="4"/>
      </measure>
      <measure number="2">
        <note pitch="S"/><note pitch="L"/><note pitch="t"/><note pitch="d"/>
      </measure>
      <measure number="3">
        <note pitch="ด"/><note pitch="ร"/><note pitch="ม"/><note pitch="ฟ"/>
      </measure>
      <measure number="4">
        <note pitch="ดํ"/><note pitch="ทฺ"/><note pitch="ด" octave="2"/><note pitch="D" octave="-2"/>
      </measure>
    </line>
  </section-ref>
</part-data>
```

ห้อง 1 ใช้ตัวเลข ห้อง 2 ใช้อักษรโรมัน ห้อง 3 ใช้อักษรไทย ส่วนห้อง 4 แสดงเครื่องหมายกำกับ ได้แก่ นิคหิต (ดํ) พินทุ (ทฺ) และแอตทริบิวต์ `octave`
