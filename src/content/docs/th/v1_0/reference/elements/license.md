องค์ประกอบ `<license>` ระบุเงื่อนไขที่โน้ตนี้เผยแพร่

เงื่อนไขครอบคลุมโน้ตในฐานะเอกสาร ไม่ใช่ดนตรี เพลงโบราณทั่วไปไม่ใช่ของใครที่จะอนุญาต แต่การถอดเป็นลายลักษณ์อักษรเป็นผลงานที่มีผู้แต่ง ไฟล์ที่ส่งต่อระหว่างคนจึงควรมีข้อมูลสถานะ

## องค์ประกอบแม่

[`<header>`](/th/v1_0/reference/elements/header/)

## เนื้อหา

ข้อความ URL หรือตัวระบุมาตรฐานให้เครื่องมือนำไปใช้ต่อได้ง่ายกว่าคำอธิบายเป็นข้อความ

## ตัวอย่าง

```xml
<license>CC BY-SA 4.0</license>
```

```xml
<license>https://creativecommons.org/licenses/by-sa/4.0/</license>
```

## หมายเหตุ

- เป็นทางเลือก ไม่เกินหนึ่งต่อโน้ต
- การไม่ใส่องค์ประกอบนี้ไม่ได้บอกอะไรเกี่ยวกับเงื่อนไข และไม่ได้แปลว่าโน้ตนี้เป็นสาธารณสมบัติ

## การแสดงผล

ลิขสิทธิ์ไม่พิมพ์บนโน้ตไทยตามธรรมเนียม ดู [แถบหัวเรื่อง](/th/v1_0/reference/rendering/#แถบหัวเรื่อง)
