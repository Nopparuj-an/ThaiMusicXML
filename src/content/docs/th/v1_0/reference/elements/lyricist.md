องค์ประกอบ `<lyricist>` ระบุชื่อผู้แต่งคำร้อง

## องค์ประกอบแม่

[`<header>`](/th/v1_0/reference/elements/header/)

## เนื้อหา

เป็นข้อความธรรมดา หรือลูก [`<text>`](/th/v1_0/reference/elements/text/) ได้ไม่เกินสามตัว ตัวละหนึ่งตำแหน่งจัด ใช้รูปแบบเนื้อหาเดียวกับ [`<annotation>`](/th/v1_0/reference/elements/annotation/#เนื้อหา) `align` จำเป็นในทุกตัว รับค่า `left`, `center`, หรือ `right` และแต่ละตำแหน่งจัดปรากฏได้ไม่เกินหนึ่งครั้ง

ข้อความธรรมดาจะจัดกึ่งกลาง ต่างจาก `<annotation>` ที่จัดชิดซ้าย เพราะข้อมูลเครดิตอยู่ใต้ชื่อเพลง ไม่ใช่อยู่ในตัวโน้ต

ข้อความพิมพ์ออกมาตามที่เขียนไว้ทุกตัวอักษร ไม่มีการเติมคำนำหน้าหรือต่อท้ายใด ๆ ดังนั้นโน้ตที่เขียนว่า `ผู้แต่งคำร้อง : Example Lyricist` ก็คือโน้ตที่ผู้เรียบเรียงพิมพ์ข้อความทั้งหมดนี้เข้าไปเอง เครื่องมือที่อ่านค่านี้เป็นเมตาดาต้าก็ใช้ข้อความชุดเดียวกัน โดยต่อลูก `<text>` เรียงจากซ้ายไปขวาเมื่อมีหลายตัว

## ตัวอย่าง

```xml
<header>
  <lyricist>Example Lyricist</lyricist>
</header>
```

```xml
<!-- จัดขวา พร้อมป้ายที่ผู้เรียบเรียงต้องการ -->
<header>
  <lyricist>
    <text align="right">ผู้แต่งคำร้อง : Example Lyricist</text>
  </lyricist>
</header>
```

## หมายเหตุ

- เป็นทางเลือก ละไว้สำหรับเพลงบรรเลง หรือเมื่อไม่ทราบผู้แต่งคำร้อง
- ใช้ `<lyricist>` หนึ่งตัวต่อคนเมื่อมีหลายคน
- ระบุเฉพาะผู้แต่ง คำร้องอยู่ใน [พาร์ตเนื้อเพลง](/th/v1_0/reference/elements/part/#ประเภทพาร์ต) เป็นองค์ประกอบ [`<syllable>`](/th/v1_0/reference/elements/syllable/) บนกริด
- แสดงผลในแถบหัวเรื่อง ดู [แถบหัวเรื่อง](/th/v1_0/reference/rendering/#แถบหัวเรื่อง)

## การสอดคล้องมาตรฐาน

- เมื่อ `<lyricist>` มีลูก `<text>` เนื้อหาถือตามลูกเหล่านั้น ส่วนข้อความพี่น้องที่เหลือถูกละเลย ตัวตรวจสอบควรแจ้งเตือนหากข้อความที่ถูกละเลยไม่ใช่ช่องว่างล้วน
- ลูก `<text>` ไม่เกินหนึ่งตัวต่อค่า `align`
