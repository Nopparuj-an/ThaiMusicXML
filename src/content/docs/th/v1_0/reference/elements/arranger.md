องค์ประกอบ `<arranger>` ระบุชื่อผู้เรียบเรียงเพลงนี้

เพลงไทยเดิมส่วนใหญ่เป็นเพลงเก่าแก่ที่ไม่ทราบผู้แต่ง โน้ตจึงมักไม่มีผู้ประพันธ์ แต่มีผู้เรียบเรียงที่ระบุตัวได้: คนที่เรียบเรียงเพลงให้วงนี้ ขยายเป็นชั้นอื่น หรือจดบันทึกฉบับของครู

## องค์ประกอบแม่

[`<header>`](/th/v1_0/reference/elements/header/)

## เนื้อหา

เป็นข้อความธรรมดา หรือลูก [`<text>`](/th/v1_0/reference/elements/text/) ได้ไม่เกินสามตัว ตัวละหนึ่งตำแหน่งจัด ใช้รูปแบบเนื้อหาเดียวกับ [`<annotation>`](/th/v1_0/reference/elements/annotation/#เนื้อหา) `align` จำเป็นในทุกตัว รับค่า `left`, `center`, หรือ `right` และแต่ละตำแหน่งจัดปรากฏได้ไม่เกินหนึ่งครั้ง

ข้อความธรรมดาจะจัดกึ่งกลาง ต่างจาก `<annotation>` ที่จัดชิดซ้าย เพราะข้อมูลเครดิตอยู่ใต้ชื่อเพลง ไม่ใช่อยู่ในตัวโน้ต

ข้อความพิมพ์ออกมาตามที่เขียนไว้ทุกตัวอักษร ไม่มีการเติมคำนำหน้าหรือต่อท้ายใด ๆ ดังนั้นโน้ตที่เขียนว่า `ผู้เรียบเรียง : Example Arranger` ก็คือโน้ตที่ผู้เรียบเรียงพิมพ์ข้อความทั้งหมดนี้เข้าไปเอง เครื่องมือที่อ่านค่านี้เป็นเมตาดาต้าก็ใช้ข้อความชุดเดียวกัน โดยต่อลูก `<text>` เรียงจากซ้ายไปขวาเมื่อมีหลายตัว

## ตัวอย่าง

```xml
<header>
  <arranger>Example Arranger</arranger>
</header>
```

```xml
<!-- จัดขวา พร้อมป้ายที่ผู้เรียบเรียงต้องการ -->
<header>
  <arranger>
    <text align="right">ผู้เรียบเรียง : Example Arranger</text>
  </arranger>
</header>
```

## หมายเหตุ

- เป็นทางเลือก ละไว้เมื่อไม่ทราบผู้เรียบเรียงหรือไม่เกี่ยวข้อง
- ใช้ `<arranger>` หนึ่งตัวต่อคนเมื่อมีหลายคนร่วมเรียบเรียง
- แสดงผลในแถบหัวเรื่อง ดู [แถบหัวเรื่อง](/th/v1_0/reference/rendering/#แถบหัวเรื่อง)

## การสอดคล้องมาตรฐาน

- เมื่อ `<arranger>` มีลูก `<text>` เนื้อหาถือตามลูกเหล่านั้น ส่วนข้อความพี่น้องที่เหลือถูกละเลย ตัวตรวจสอบควรแจ้งเตือนหากข้อความที่ถูกละเลยไม่ใช่ช่องว่างล้วน
- ลูก `<text>` ไม่เกินหนึ่งตัวต่อค่า `align`
