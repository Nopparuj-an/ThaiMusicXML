title: <tuning>
description: การอ้างอิงระดับเสียงที่โน้ตตั้งอยู่
---

องค์ประกอบ `<tuning>` ระบุว่าดีกรีของระบบเสียงในโน้ตนี้แทนระดับเสียงสัมบูรณ์ใด

ค่า `pitch` ระบุดีกรีของระบบเสียงไทย ไม่ใช่ความถี่ ด เป็นดีกรีแรกที่ใดก็ตามที่วงปรับเสียง ไม่มี `<tuning>` เอกสารบอกว่าจะเล่นอะไรเมื่อเทียบกับวงแต่ไม่บอกว่าระดับเสียงใด เพียงพอสำหรับพิมพ์โน้ตไม่เพียงพอสำหรับเล่น

## องค์ประกอบแม่

[`<header>`](/th/v1_0/reference/elements/header/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| ----------- | -------- | ------ | ---------------------------------------- |
| `reference` | ใช่ | สตริง | การปรับเสียงที่ ด ตั้ง ดูด้านล่าง |

## ค่า

`reference` เป็นสตริงอิสระ ค่าด้านล่างเป็นค่าที่ควรสะกดให้สม่ำเสมอ แต่รายการเป็นจุดเริ่มต้นไม่ใช่ชุดปิด

| ค่า | คำอธิบาย |
| ----- | ----------- |
| `pi-phat-mai-khaeng` | ปี่พาทย์ไม้แข็ง ที่ระดับเสียงอ้างอิงกรมศิลปากร |
| `khrueang-sai` | เครื่องสาย และมโหรี ที่ระดับเสียงอ้างอิงกรมศิลปากร |
| `c-major` | ด เสียงเป็น C ทางเลือกปกติสำหรับสื่อการสอนและโน้ตที่ใช้ร่วมกับเครื่องดนตรีตะวันตก |
| `bb-major` | ด เสียงเป็น B♭ ค่าที่ใกล้ที่สุดสำหรับวงเครื่องสายไทย |

การปรับเสียงกว้างกว่าสี่ค่า การกำหนดชุดตอนนี้จะปฏิเสธโน้ตที่อธิบายได้ด้วยชื่อที่รายการยังไม่ถึง ตัวตรวจสอบจึงรับสตริงใดก็ได้และแจ้งเตือนเมื่อไม่รู้จัก ซึ่งยังจับ `c-majro` ได้โดยไม่ทำให้การปรับเสียงที่ไม่ปกติกลายเป็นเอกสารที่ไม่ถูกต้อง [`<nathap>`](/th/v1_0/reference/elements/nathap/) เปิดด้วยเหตุผลเดียวกัน [`<chan>`](/th/v1_0/reference/elements/chan/) ไม่เปิด เพราะห้าระดับเป็นชุดทั้งหมด

## ตัวอย่าง

```xml
<header>
  <title>แขกบรเทศ ชั้นเดียว</title>
  <tuning reference="khrueang-sai" />
</header>
```

## หมายเหตุ

- การปรับเสียงไทยแบ่ง octave ออกเป็นเจ็ดขั้นเกือบเท่ากัน คีย์ตะวันตกจึงไม่มีตัวใดตรงพอดี ค่า `c-major` และ `bb-major` ระบุการเทียบที่ใกล้เคียงที่สุด ไม่ใช่ความเหมือนกันทุกประการ
- `<tuning>` เป็นทางเลือก โน้ตที่มีไว้อ่านเท่านั้น หรือโน้ตที่ไม่ทราบการปรับเสียง อาจละไว้

## การสอดคล้องมาตรฐาน

- `reference` จำเป็นและเป็นสตริงที่ไม่ว่างใดก็ได้
- ตัวตรวจสอบควรแจ้งเตือนเมื่อ `reference` อยู่นอกรายการแนะนำข้างบน และต้องไม่ปฏิเสธ
- ไม่เกินหนึ่ง `<tuning>` ต่อ [`<header>`](/th/v1_0/reference/elements/header/)
