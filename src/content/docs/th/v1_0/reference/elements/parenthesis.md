องค์ประกอบ `<parenthesis>` ระบุช่วงของ [`<note>`](/th/v1_0/reference/elements/note/) และ [`<rest>`](/th/v1_0/reference/elements/rest/) เป็นช่วงอ้างอิง ไม่ใช่เล่น: พาร์ตรอเครื่องดนตรีอื่นในความสัมพันธ์ผู้นำ-ผู้ตามบรรเลงช่วงนั้น

## องค์ประกอบแม่

[`<measure>`](/th/v1_0/reference/elements/measure/) หรือ [`<group>`](/th/v1_0/reference/elements/group/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| --------- | -------- | --------------------- | -------------------------------------------------------------------------------------------------------------- |
| `type` | ใช่ | `"start"` \| `"stop"` | ตัวเปิดหรือตัวปิดช่วง |
| `dim` | ไม่ | บูลีน | แทนที่ค่าเริ่มต้นของตัวแสดงผลสำหรับแสดงช่วงสีจางลง ใช้ได้เฉพาะบน `type="start"` |
| `mute` | ไม่ | บูลีน | แทนที่ค่าเริ่มต้นของตัวแสดงผลสำหรับปิดเสียงช่วง ใช้ได้เฉพาะบน `type="start"` |

## ความหมาย

`<parenthesis type="start"/>` กับ `<parenthesis type="stop"/>` ตัวถัดไปที่พาร์ตพบจะครอบช่วงหนึ่งเอาไว้ด้วยกัน โน้ตและตัวหยุดทุกตัวที่อยู่ระหว่างสองตัวนี้ถือเป็นช่วงอ้างอิง

การจับคู่ตามลำดับเอกสารภายในรอบที่แก้ไขแล้ว ตัวในห้องหนึ่งอาจถูกปิดด้วยตัวในห้องหรือบรรทัดถัดไป ช่วงจึงข้ามขอบเขต `<measure>`, `<group>`, และ `<line>` ได้ แต่ไม่ข้ามขอบเขตท่อน

ในท่อนที่เล่นครั้งเดียว และในท่อนที่ไม่มี [`<ending>`](/th/v1_0/reference/elements/ending/) เป็นลำดับเอกสารธรรมดา เมื่อมี ending แทนที่บรรทัด แก้ไขรอบก่อนแล้วจับคู่ภายในบรรทัดที่รอบนั้นเล่นจริง ดู [ช่วงที่ข้ามบรรทัดที่ถูกแทนที่](/th/v1_0/reference/elements/ending/#ช่วงที่ข้ามบรรทัดที่ถูกแทนที่)

`<line-repeat>` ไม่เกี่ยวข้อง บรรทัดถูกอ่านครั้งเดียวตามลำดับที่เขียน ไม่ว่าจะเล่นกี่ครั้ง ช่วงหนึ่งอาจเปิดในช่วงที่ซ้ำแล้วปิดหลังจากนั้น และช่วงที่ปิดไปแล้วในช่วงที่ซ้ำก็จะไม่เปิดขึ้นใหม่เมื่อวนมาเล่นซ้ำอีกครั้ง

มาร์กอัปนี้ระบุเพียงขอบเขตของช่วงเท่านั้น ส่วนจะแสดงเป็นสีจางลงหรือถูกปิดเสียงระหว่างเล่นหรือไม่ เป็นค่าเริ่มต้นที่ตัวแสดงผลหรือตัวเล่นกำหนดเอง `dim` และ `mute` ใช้แทนที่ค่าเริ่มต้นเหล่านั้นสำหรับช่วงหนึ่ง ๆ เนื่องจากอธิบายช่วงทั้งหมด จึงปรากฏบนตัว `start` เท่านั้น ดู [ช่วงที่อ้างอิง](/th/v1_0/reference/rendering/#ช่วงที่อ้างอิง)

## ตัวอย่าง

```xml
<measure number="3">
  <parenthesis type="start"/>
  <note pitch="ซ"/>
  <note pitch="ม"/>
  <parenthesis type="stop"/>
  <note pitch="ซ"/>
  <note pitch="ม"/>
</measure>
```

```xml
<!-- ช่วงข้ามขอบเขตห้อง -->
<line number="2">
  <measure number="1">
    <parenthesis type="start" dim="false"/>
    <note pitch="ด"/>
    <note pitch="ร"/>
    <note pitch="ม"/>
    <note pitch="ซ"/>
  </measure>
  <measure number="2">
    <note pitch="ล"/>
    <note pitch="ซ"/>
    <note pitch="ม"/>
    <note pitch="ร"/>
    <parenthesis type="stop"/>
  </measure>
</line>
```

## การสอดคล้องมาตรฐาน

- ในทุกรอบที่แก้ไขแล้วของท่อน `type="start"` ต้องถูกปิดด้วย `type="stop"` ที่ตรงกันก่อนที่ `type="start"` อื่นจะปรากฏ ช่วง parenthesis ไม่สามารถซ้อนหรือทับซ้อนกัน
- ในทุกรอบที่แก้ไขแล้ว `type="start"` ทุกตัวต้องมี `type="stop"` ที่ตรงกันภายใน `<section-ref>` เดียวกัน ช่วงที่เปิดค้างไว้เมื่อจบรอบไม่ถูกต้อง แม้อีกจะปิดก็ตาม
- `dim` และ `mute` ใช้ได้เฉพาะบนตัว `type="start"`
- ช่วง parenthesis เป็นอิสระต่อพาร์ต การระบุช่วงในโน้ตของพาร์ตหนึ่งไม่มีผลกับพาร์ตอื่น
