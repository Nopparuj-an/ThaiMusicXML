องค์ประกอบ `<group>` แบ่งจังหวะเดียวเป็นสองส่วนขึ้นไปเท่า ๆ กัน สำหรับห้องที่อัดโน้ตมากกว่าปกติในจังหวะเดียว

## องค์ประกอบแม่

[`<measure>`](/th/v1_0/reference/elements/measure/)

## แอตทริบิวต์

ไม่มี

## ลูก

ลำดับของ [`<note>`](/th/v1_0/reference/elements/note/) และ [`<rest>`](/th/v1_0/reference/elements/rest/) สองตัวขึ้นไป ลำดับใดก็ได้ อาจแทรก [`<bow>`](/th/v1_0/reference/elements/bow/), [`<parenthesis>`](/th/v1_0/reference/elements/parenthesis/), และ [`<link>`](/th/v1_0/reference/elements/link/)

## ความหมาย

`<group>` ใช้หนึ่งจังหวะพอดี ช่วงเวลาเดียวกับ `<note>` หรือ `<rest>` เดี่ยวที่ตำแหน่งเดียวกันใน `<measure>` จังหวะนั้นแบ่งเท่า ๆ กันในลูก `<note>` และ `<rest>` ของกลุ่ม: สองลูกได้คนละครึ่งจังหวะ สามลูกได้คนละหนึ่งในสาม เป็นต้น

### ตำแหน่งที่ลูกตก

จังหวะเกิดในช่องโน้ตสุดท้าย ลูกสุดท้ายของกลุ่มจึงตกบนจังหวะ ส่วนตัวก่อนหน้าถอยหลังจากจุดนั้นอย่างสม่ำเสมอ

นี่คือจุดที่การแบ่งย่อยของไทยแยกจากตะวันตก ควรทำความเข้าใจให้ชัด ลอง `ด ร ม ซ` เทียบกับ `ด (ร ม) ซ ล` ตัว ม ของกลุ่มตกที่จังหวะที่สอง พร้อมกับตัว ร ของเวอร์ชันธรรมดา ส่วนตัว ร ของกลุ่มดังอยู่ระหว่างจังหวะแรกกับที่สอง การอ่านแบบตะวันตกจะวางตัว ร ไว้บนจังหวะแล้วให้ ม ตามมา

ทำเครื่องหมายโน้ตที่ตกจังหวะเป็น `X` และโน้ตระหว่างจังหวะเป็น `O`:

```
| -  -  - (ม ร ด) |    →    | -  -  - (O O X) |
| -  ร  -  ม      |    →    | -  X  -  X      |
| (ด ร) ม (ซ ล ท) (ดํ รํ) |    →    | (O X) X (O O X) (O X) |
```

`<note>` เปล่าเป็น `X` เสมอ: คือจังหวะ เฉพาะกลุ่มเท่านั้นที่สร้าง `O` และเฉพาะลูกที่ไม่ใช่ตัวสุดท้าย

### ทำไมกลุ่มออกจากห้องไม่ได้

จังหวะเป็นเจ้าของช่วงเวลา *ที่จบ* ที่จุดตก ไม่ใช่เริ่มจากจุดตก เขียน `d` เป็นความยาวหนึ่งช่องโน้ต จังหวะ `n` ของห้องมาถึง `n·d` จากขอบห้อง กลุ่ม `k` ลูกในจังหวะ `n` ดังที่ `n·d − (k−1)d/k` ถึง `n·d`

ลูกแรกจึงตก `(k−1)/k` ของจังหวะก่อน และเนื่องจาก `(k−1)/k` น้อยกว่า `1` เสมอ ตำแหน่งนั้นอยู่ภายในจังหวะ `n` เสมอ กลุ่มไม่เคยเข้าถึงจังหวะก่อนหน้า และไม่เคยข้ามขอบเขต `<measure>` หรือ `<line>` ไม่มีสิ่งใดบังคับ คณิตศาสตร์ไม่อนุญาต

ดู [จังหวะยึดด้านขวา](/th/v1_0/reference/rendering/#จังหวะยึดด้านขวา) สำหรับวิธีวางสัญลักษณ์บนหน้า และ [`<bpm>`](/th/v1_0/reference/elements/bpm/#การเดินช่องโน้ต) สำหรับการเล่น

`<bow>`, `<parenthesis>`, และ `<link>` ปรากฏภายใน `<group>` ข้างโน้ตและตัวหยุดได้ ไม่มีความยาวและไม่นับรวมการแบ่ง กลุ่มที่มีลูก `<note>` สองตัวและ `<bow>` หนึ่งตัวยังแบ่งจังหวะเป็นสองไม่ใช่สาม ช่วงที่เปิดหรือปิดโดยตัวเหล่านี้ข้ามขอบเขต `<group>` ได้ เหมือนที่ข้ามขอบเขต `<measure>` และ `<line>` อยู่แล้ว

กลุ่มบอกเพียงว่าจังหวะแบ่งอย่างไร ไม่บอกอย่างอื่น หากต้องการระบุว่าโน้ตชุดหนึ่งเป็นท่าทางเดียวที่เชื่อมต่อกัน และขอเส้นโค้งที่บอกเช่นนั้น ให้เขียนช่วง [`<link>`](/th/v1_0/reference/elements/link/) ครอบไว้ เพราะกลุ่มคือหนึ่งจังหวะพอดีขณะที่ท่าทางมักไม่ใช่ เครื่องหมายนั้นจึงเป็นคู่ตัวกำกับ ไม่ใช่สิ่งที่กลุ่มถือเองได้

## ตัวอย่าง

```xml
<!-- จังหวะที่ 2 แบ่งเป็นโน้ตตัวที่แปดสองตัว -->
<measure number="1">
  <note pitch="ด"/>
  <group>
    <note pitch="ร"/>
    <note pitch="ม"/>
  </group>
  <note pitch="ซ"/>
  <note pitch="ล"/>
</measure>
```

```xml
<!-- จังหวะแบ่งเป็นสาม -->
<group>
  <note pitch="ด"/>
  <note pitch="ร"/>
  <note pitch="ม"/>
</group>
```

## การสอดคล้องมาตรฐาน

- `<group>` ต้องมีลูก `<note>` หรือ `<rest>` อย่างน้อยสอง
- `<group>` ต้องไม่มี `<group>` ซ้อน การแบ่งย่อยใน ThaiMusicXML v1.0 ลึกหนึ่งชั้น
- `<bow>`, `<parenthesis>`, และ `<link>` ภายใน `<group>` ไม่นับรวมการแบ่งเท่าของจังหวะ
