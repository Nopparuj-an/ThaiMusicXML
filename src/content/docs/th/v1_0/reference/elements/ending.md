การออกเพลง

องค์ประกอบ `<ending>` แทนที่องค์ประกอบ `<line>` เฉพาะในรอบเฉพาะของท่อนที่ซ้ำ เพื่อให้พาร์ตเล่นสิ่งที่ต่างในรอบที่กำหนดโดยไม่ต้องจัดโครงสร้าง `<section-ref>` ใหม่

## องค์ประกอบแม่

[`<section-ref>`](/th/v1_0/reference/elements/section-ref/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย                                                                 |
| ----------- | ------ | ------ | ------------------------------------------------------------------------ |
| `pass`      | ใช่    | สตริง  | หมายเลขรอบที่ ending ใช้ คั่นด้วยจุลภาค นับจาก 1 เช่น `"2"` หรือ `"2,4"` |

## ลูก

ตามลำดับ:

1. [`<annotation>`](/th/v1_0/reference/elements/annotation/) - หนึ่งหรือมากกว่า อธิบายความแปรผัน
2. [`<line>`](/th/v1_0/reference/elements/line/) - หนึ่งหรือมากกว่า

ending แสดงผลใต้ท่อนแทนที่จะอยู่ในตำแหน่ง แยกจากบรรทัดที่แทนที่ ผู้อ่านต้องรู้ว่ากำลังดูอะไร นี่คือเหตุผลที่ annotation จำเป็นไม่ใช่ทางเลือก ระบุเครื่องดนตรีและโอกาสด้วยถ้อยคำที่เหมาะกับโน้ต: `ขิม รอบสุดท้ายเปลี่ยนเป็น` ระบุทั้งสอง ดู [ท่อนแปรผัน](/th/v1_0/reference/rendering/#ท่อนแปรผัน)

## ความหมาย

`<line number="N">` แต่ละตัวภายใน `<ending>` แทนที่บรรทัด `N` ในรอบที่ระบุใน `pass` บรรทัดที่มีเลขนั้นต้องมีอยู่แล้วโดยตรงใน `<section-ref>` ending แทนที่บรรทัดเท่านั้น ไม่สามารถเพิ่มหรือลบบรรทัด ท่อนจึงคงโครงสร้างเดิมในทุกรอบ

ในรอบที่ไม่มี `<ending>` ใดครอบคลุม พาร์ตเล่น `<line>` ปกติไม่เปลี่ยน `<section-ref>` ที่ไม่มี `<ending>` เล่นเหมือนกันทุกรอบ

ending แทนที่ท้ายท่อน บรรทัดต้องเรียงต่อกันจนถึงบรรทัดสุดท้าย ท่อนห้าบรรทัดจึงรับ ending ที่บรรทัด 5, ที่บรรทัด 4 และ 5, ไปจนถึงทั้งห้า แต่ไม่ใช่เฉพาะบรรทัด 3 นี่คือความหมายของคำ: ท่อนที่ดำเนินต่อตามปกติหลังความแปรผันไม่ได้จบด้วยความแปรผันนั้น

ค่า `number` ยังคงเป็นสัมบูรณ์ นับจากจุดเริ่มของท่อน เหมือนหมายเลข [`<line>`](/th/v1_0/reference/elements/line/) เสมอ ซ้ำซ้อนกับกฎข้างบนโดยเจตนา ผู้แต่งที่นับผิดเขียนเลขที่ไม่ตรงกับบรรทัดใดและได้รับข้อผิดพลาด การนับจากท้ายจะแทนที่ผิดโดยไม่แจ้ง

### หมายเลขรอบ

`pass` นับรอบสัมบูรณ์ของท่อน จากเล่นครั้งแรกถึงครั้งสุดท้าย ไม่ว่าชั้น [`<repeat>`](/th/v1_0/reference/elements/repeat/) ใดสร้างรอบนั้น ท่อนที่ซ้อนในสอง `times="2"` มีรอบทั้งหมด 4 `pass="4"` จึงระบุเล่นครั้งสุดท้ายและ `pass="2,4"` ใส่ความแปรผันต่างกันในสองจุด

### ช่วงที่ข้ามบรรทัดที่ถูกแทนที่

[`<bow>`](/th/v1_0/reference/elements/bow/) และ [`<parenthesis>`](/th/v1_0/reference/elements/parenthesis/) จับคู่ตามลำดับที่บรรทัดถูกอ่านเมื่อรอบถูกแก้ไขแล้ว ไม่ใช่ลำดับในไฟล์ `<ending>` อยู่หลังบรรทัดปกติทั้งหมดในเอกสารแต่ยืนแทนหนึ่งในนั้น ลำดับทั้งสองจึงแยกเมื่อช่วงเข้าถึงบรรทัดที่ ending แทนที่

แก้ไขรอบก่อน แล้วจับคู่ ใช้บรรทัดที่พาร์ตเล่นจริงในรอบนั้น บรรทัดปกติพร้อมการแทนที่ของ ending แล้วจับคู่ `start` กับ `stop` ถัดไปในลำดับนั้น แต่ละรอบจับคู่แยก

ช่วงที่เข้าถึงบรรทัดที่ถูกแทนที่จึงต้องมี `stop` ในทั้งสองเวอร์ชัน: ครั้งหนึ่งในบรรทัดปกติสำหรับรอบที่เล่น และอีกครั้งในบรรทัด ending สำหรับรอบที่เล่นแทน

```xml
<section-ref section="s1">
  <line number="1">
    <measure number="1">
      <bow type="start" direction="out"/>
      <note pitch="ซ"/><note pitch="ล"/><note pitch="ดํ"/><note pitch="ล"/>
    </measure>
  </line>
  <line number="2">
    <measure number="1">
      <note pitch="ซ"/><note pitch="ม"/>
      <bow type="stop"/>
      <note pitch="ร"/><note pitch="ด"/>
    </measure>
  </line>

  <ending pass="2">
    <annotation>เที่ยวที่ 2 จบคันชักเร็วขึ้นหนึ่งตัว</annotation>
    <line number="2">
      <measure number="1">
        <note pitch="ซ"/>
        <bow type="stop"/>
        <note pitch="ม"/><note pitch="ร"/><note pitch="ด"/>
      </measure>
    </line>
  </ending>
</section-ref>
```

bow เปิดในบรรทัด 1 ทั้งสองรอบ รอบ 1 ปิดที่โน้ตที่สองของบรรทัด 2 รอบ 2 ปิดเร็วขึ้นหนึ่งโน้ต ไม่มีรอบใดเห็น `stop` มากกว่าหนึ่ง เพราะไม่มีรอบใดเล่นทั้งสองเวอร์ชันของบรรทัด 2

การไม่ใส่ `stop` ในบรรทัด ending เป็นข้อผิดพลาด ไม่ใช่รูปย่อ: รอบนั้นจะจบโดยช่วงยังเปิดอยู่

## การสอดคล้องมาตรฐาน

- `<ending>` ใช้ได้เฉพาะภายใน `<section-ref>` ที่ท่อนมีรอบทั้งหมดมากกว่า `1` ดู [`<repeat>`](/th/v1_0/reference/elements/repeat/#จำนวนรอบทั้งหมด)
- ค่า `pass` ทุกค่าต้องเป็นจำนวนเต็มจาก `1` ถึงรอบทั้งหมดของท่อน เรียงจากน้อยไปมากไม่ซ้ำ
- `<line number="N">` แต่ละตัวใน `<ending>` ต้องตรงกับ `number` ของบรรทัดที่มีอยู่แล้วใน `<section-ref>` ที่ครอบ
- บรรทัดของ `<ending>` ต้องเรียงต่อกันจนถึงบรรทัดสุดท้ายของท่อน เรียงจากน้อยไปมาก ending ที่ครอบเฉพาะบรรทัดกลางไม่ถูกต้อง
- บรรทัด `<ending>` ต้องมีจำนวน `<measure>` เท่ากับบรรทัดที่แทนที่ และห้องที่ตรงกันต้องมีจำนวนจังหวะเท่ากัน สิ่งนี้รักษา [กฎการซิงค์ข้ามพาร์ต](/th/v1_0/reference/elements/section-ref/#การสอดคล้องมาตรฐาน): ในรอบใดก็ตาม เมื่อ ending ของทุกพาร์ตถูกแก้ไขแล้ว พาร์ตทั้งหมดที่อ้างท่อนยังตรงกันเรื่องจำนวนบรรทัด ห้อง และจังหวะ เฉพาะโน้ตภายในห้องเท่านั้นที่ต่างกันได้
- `<ending>` สองตัวใน `<section-ref>` เดียวกันต้องไม่ครอบหมายเลขบรรทัดเดียวกันในรอบเดียวกัน
- `<ending>` ต้องมี `<annotation>` อย่างน้อยหนึ่งตัว ending พิมพ์แยกจากบรรทัดที่แทนที่ จึงต้องมีคำอธิบายว่าเป็นของพาร์ตใดและใช้เมื่อใด

## ตัวอย่าง

```xml
<part-data part="P1">
  <section-ref section="s1">
    <line number="1"><!-- ... --></line>
    <line number="2"><!-- ... --></line>
    <line number="3"><!-- ... --></line>

    <ending pass="2">
      <annotation>แทนที่บรรทัดสุดท้ายในเที่ยวที่ 2 (Replace last line on pass 2)</annotation>
      <line number="3"><!-- ความแปรผัน จำนวนห้องเท่ากับบรรทัด 3 ข้างบน --></line>
    </ending>
  </section-ref>
</part-data>

<part-data part="P2">
  <!-- ไม่มี <ending>: พาร์ตนี้เล่นสามบรรทัดเดิมทุกรอบ -->
  <section-ref section="s1">
    <line number="1"><!-- ... --></line>
    <line number="2"><!-- ... --></line>
    <line number="3"><!-- ... --></line>
  </section-ref>
</part-data>
```
