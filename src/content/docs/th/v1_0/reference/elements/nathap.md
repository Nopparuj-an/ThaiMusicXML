องค์ประกอบ `<nathap>` ระบุหน้าทับที่เพลงตั้งอยู่

หน้าทับคือรอบกลองที่บทเพลงดำเนินตาม บรรเลงโดยเครื่องดนตรีอย่างตะโพน กลองแขก และโทน-รำมะนา หน้าทับกำหนดความยาวของรอบและรูปแบบจังหวะตีภายในรอบนั้น นักดนตรีที่รู้หน้าทับจะรู้โครงสร้างของเพลงตั้งแต่ก่อนอ่านโน้ตสักตัว

## องค์ประกอบแม่

[`<direction>`](/th/v1_0/reference/elements/direction/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| --------- | -------- | ------ | ------------------------------------ |
| `value`   | ใช่ | สตริง | ชื่อรอบ ดูด้านล่าง |

## ค่า

`value` เป็นสตริงอิสระ รอบด้านล่างเป็นรอบที่ควรสะกดให้สม่ำเสมอ แต่รายการเป็นจุดเริ่มต้นไม่ใช่ชุดปิด โน้ตอาจระบุรอบใดก็ได้ที่เล่น

| ค่า | หมายเหตุ |
| ----- | ----- |
| `ปรบไก่` | หนึ่งในสองรอบหลักของปี่พาทย์ |
| `สองไม้` | อีกรอบ สั้นกว่าและสม่ำเสมอกว่า |
| `ลาว` | หน้าทับ สำเนียงลาว |
| `เขมร` | หน้าทับ สำเนียงเขมร |
| `มอญ` | หน้าทับ สำเนียงมอญ |

ชุดค่านี้ยังไม่ปิดตายตัวใน v1.0 เพราะหน้าทับมีมากกว่าที่จะระบุให้ครบตอนนี้ได้ และชุดปิดจะทำให้โน้ตที่ถูกต้องถูกปฏิเสธไปด้วย การเขียนค่าที่ไม่อยู่ในรายการนี้ยังถือว่าใช้ได้ ตัวตรวจสอบจะแจ้งเตือนแทนที่จะปฏิเสธ เพื่อให้เห็นการสะกดผิดของชื่อที่รู้จักอยู่ดี

## ตัวอย่าง

```xml
<direction>
  <nathap value="ปรบไก่" />
  <chan value="1" />
  <bpm>60</bpm>
</direction>
```

## หน้าที่

ไม่มีผลใน v1.0 `<nathap>` เพียงบันทึกไว้ว่าเพลงตั้งตามรอบใด แล้วส่งต่อให้ซอฟต์แวร์ที่อ่านไฟล์ องค์ประกอบนี้ไม่มีโครงสร้างที่แทนตัวรอบเอง จึงคำนวณจังหวะตีจากมันไม่ได้ และตัวเล่นก็เล่นเสียงออกมาจากมันไม่ได้เช่นกัน

หากมีการเขียนพาร์ตกลองจริง ก็เขียนเป็นพาร์ตธรรมดาอย่าง [`<part type="unpitched">`](/th/v1_0/reference/elements/part/#ประเภทพาร์ต) พร้อมรหัส `sound` เหมือนเครื่องดนตรีอื่น `<nathap>` เพียงระบุว่าพาร์ตนั้นเล่นอะไร ไม่ได้สร้างมันขึ้นมา ส่วนตัวเล่นจะนำชื่อนี้ไปใช้อย่างไรก็เป็นเรื่องของตัวเล่นเอง

เช่นเดียวกับ [`<chan>`](/th/v1_0/reference/elements/chan/) นี่คือเมตาดาต้าสำหรับไฟล์ ตัวแก้ไข และตัวเล่น ไม่ใช่สิ่งที่หน้าโน้ตแสดงผล หากมีการพิมพ์ `หน้าทับปรบไก่` เหนือกริด นั่นเป็นเพราะผู้เรียบเรียงเขียนไว้ใน [`<annotation>`](/th/v1_0/reference/elements/annotation/)

## การสอดคล้องมาตรฐาน

- `value` จำเป็นและเป็นสตริงที่ไม่ว่างใดก็ได้
- ตัวตรวจสอบควรแจ้งเตือนเมื่อ `value` อยู่นอกรายการแนะนำข้างบน และต้องไม่ปฏิเสธ
- ไม่เกินหนึ่ง `<nathap>` ต่อ [`<direction>`](/th/v1_0/reference/elements/direction/)
