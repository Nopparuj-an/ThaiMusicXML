องค์ประกอบ `<bpm>` ตั้งจังหวะเป็นจังหวะต่อนาที

## องค์ประกอบแม่

[`<direction>`](/th/v1_0/reference/elements/direction/)

## หน่วยที่นับ

หนึ่งจังหวะ bpm เท่ากับ**สอง**จังหวะห้อง หมายถึงช่องโน้ต `<note>`, `<rest>`, หรือ `<group>` สองช่องติดกัน ตามที่นิยามไว้ใน [`<measure>`](/th/v1_0/reference/elements/measure/#จังหวะ) ที่ `<bpm>90</bpm>` โน้ตจะเล่น 180 ช่องโน้ตต่อนาที

ตัวคูณสองมีอยู่เพราะช่องโน้ตเป็นหน่วยย่อยของจังหวะ ไม่ใช่จังหวะหลัก การเคาะตามทุกช่องโน้ตของห้องที่มีสี่ช่องจะได้จำนวนเป็นสองเท่าของสิ่งที่นักดนตรีเรียกว่าจังหวะ เหมือนกับการนับโน้ตตัวที่แปดที่ได้ตัวเลขเป็นสองเท่าของจังหวะแบบตะวันตก การนับเป็นคู่แบบนี้ทำให้ตัวเลขจังหวะของ ThaiMusicXML อยู่ในสเกลเดียวกับที่คนทั่วไปใช้เรียกกันจริง ๆ

## การเดินช่องโน้ต

หนึ่งช่องโน้ตมีความยาว `30 / bpm` วินาที เพราะหนึ่งจังหวะ bpm ครอบสองช่อง ที่ `<bpm>90</bpm>` จึงเท่ากับหนึ่งในสามวินาที

โน้ตแต่ละตัวจะดังขึ้นห่างกันเป็นช่วงเท่า ๆ กัน เว้นแต่มี [`<group>`](/th/v1_0/reference/elements/group/) มาคั่น ตัวเล่นจึงเดินไปตามช่องโน้ตทีละช่องตามช่วงนั้น และแบ่งย่อยแต่ละกลุ่มแบบนับถอยหลังภายในช่องโน้ตของตัวเอง จังหวะที่ `n` ของห้องจะมาถึงที่ช่องโน้ตลำดับที่ `n` นับจากขอบห้อง โน้ตตัวสุดท้ายของห้องจึงตกที่ขอบปิดพอดี ดู [ตำแหน่งที่ลูกตก](/th/v1_0/reference/elements/group/#ตำแหน่งที่ลูกตก)

ผลที่ตามมาอย่างหนึ่งจากการที่จังหวะตกท้ายช่องโน้ตคือ โน้ตตัวแรกของเพลงจะดังขึ้นหนึ่งช่องโน้ตหลังจุดศูนย์ ไม่ใช่ที่จุดศูนย์พอดี ไฟล์ ThaiMusicXML ไม่มีไทม์ไลน์แน่นอนอยู่แล้ว ออฟเซ็ตนี้จึงไม่มีผลกระทบใด ๆ ตัวเล่นจะเริ่มเล่นที่โน้ตตัวแรกไปเลยก็ได้ เรื่องนี้จะสำคัญก็ต่อเมื่อต้องซิงค์กับนาฬิกาภายนอก ซึ่งขอบแรกของห้องแรกเป็นจุดอ้างอิง และโน้ตตัวแรกจะอยู่ถัดไปอีกหนึ่งช่องโน้ต

## ความสัมพันธ์กับชั้น

จังหวะกับ [`<chan>`](/th/v1_0/reference/elements/chan/) เป็นอิสระต่อกัน การเปลี่ยนชั้นที่ `<bpm>` คงที่ไม่เร่งหรือชะลอเพลง

จังหวะ bpm คงที่อยู่ที่สองช่องโน้ตเสมอไม่ว่าจะอยู่ชั้นใด โน้ตจึงคงอัตราเดิมไว้ตลอดการเปลี่ยนชั้น สิ่งที่เปลี่ยนไปคือฉิ่ง เมื่อขยายจากชั้นเดียวเป็นสองชั้น ทำนองจะยืดออกเป็นสองเท่าของจำนวนช่องโน้ต รอบของฉิ่งก็ยืดตามไปด้วย ทำให้จังหวะฉิ่งตกห่างลงครึ่งหนึ่ง เพลงยังเล่นด้วยความเร็วเท่าเดิม เพียงแต่รอบฉิ่งด้านล่างห่างขึ้น

## เนื้อหา

จำนวนเต็ม

## ตัวอย่าง

```xml
<bpm>90</bpm>
```

เก้าสิบจังหวะต่อนาที เท่ากับ 180 ช่องโน้ตต่อนาที เมื่อห้องหนึ่งมีสี่ช่อง จึงเท่ากับสี่สิบห้าห้องต่อนาที
