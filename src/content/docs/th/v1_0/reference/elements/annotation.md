---

องค์ประกอบ `<annotation>` บรรจุหมายเหตุอิสระที่ละเลยระหว่างการเล่น อาจมีข้อความค่าเดียว หรือข้อความที่จัดตำแหน่งได้ไม่เกินสามค่าบนบรรทัดเดียวกัน

ขอบเขตของมันขึ้นอยู่กับตำแหน่งที่วาง หมายเหตุใน `<structure>` มีผลกับโน้ตทั้งฉบับ ส่วนหมายเหตุที่อยู่ใน `<section-ref>` หรือ `<ending>` มีผลกับพาร์ตนั้นเพียงพาร์ตเดียว ซึ่งเป็นวิธีบันทึกธรรมเนียมการเขียนโน้ตเฉพาะของแต่ละเครื่องดนตรี

## องค์ประกอบแม่

- [`<structure>`](/th/v1_0/reference/elements/structure/)
- [`<repeat>`](/th/v1_0/reference/elements/repeat/)
- [`<section-ref>`](/th/v1_0/reference/elements/section-ref/)
- [`<ending>`](/th/v1_0/reference/elements/ending/)

## เนื้อหา

ข้อความธรรมดา หรือลูก [`<text>`](/th/v1_0/reference/elements/text/) หนึ่งตัวต่อหนึ่งตำแหน่งจัดวาง ลูก `<text>` ไม่จำเป็นต้องมี แต่แต่ละตำแหน่งจัดวางปรากฏได้เพียงครั้งเดียว

| ลูก | จำเป็น | คำอธิบาย |
| ----- | -------- | ----------- |
| `<text align="left">` | ไม่ | ข้อความจัดชิดขอบซ้าย |
| `<text align="center">` | ไม่ | ข้อความจัดกลาง |
| `<text align="right">` | ไม่ | ข้อความจัดชิดขอบขวา |

แอตทริบิวต์ `align` รับค่า `left`, `center`, หรือ `right` ตัวแสดงผลจะมองลูกเหล่านี้เป็นสามตำแหน่งแยกกันบนบรรทัดเดียว ไม่ใช่ข้อความที่เรียงต่อกัน

ข้อความธรรมดาเป็นรูปแบบย่อของข้อความจัดชิดซ้าย

เมื่อองค์ประกอบมีลูก `<text>` ลูกเหล่านั้นจะเป็นเนื้อหาทั้งหมด ส่วนข้อความอื่นที่อยู่ข้าง ๆ จะถูกละเลยไป นี่คือสิ่งที่ทำให้เยื้อง `<annotation>` ข้ามหลายบรรทัดได้โดยไม่ทำให้ช่องว่างกลายเป็นเนื้อหา ข้อความที่ไม่ใช่ช่องว่างล้วนก็ยังถูกละทิ้งเช่นกัน ตัวตรวจสอบจึงแจ้งเตือน

## ตัวอย่าง

```xml
<annotation>บรรทัดที่ 1 มี 7 ห้อง</annotation>
```

```xml
<annotation>
  <text align="left">ท่อน 1</text>
  <text align="center">Lao Duang Duen</text>
  <text align="right">หน้า 1</text>
</annotation>
```

```xml
<annotation>
  <text align="center">Centered annotation</text>
</annotation>
```

```xml
<!-- ภายใน <section-ref>: บันทึกธรรมเนียมการเขียนโน้ตของเครื่องดนตรี -->
<annotation>0 = ฉิ่ง / 1 = ฉับ</annotation>
```

## การสอดคล้องมาตรฐาน

- มีลูก `<text>` ได้ไม่เกินหนึ่งตัวต่อค่า `align` หนึ่งค่า
- เมื่อ `<annotation>` มีลูก `<text>` ลูกเหล่านั้นคือเนื้อหาทั้งหมด ข้อความพี่น้องอื่นจะถูกละเลย ตัวตรวจสอบควรแจ้งเตือนเมื่อข้อความที่ถูกละเลยไม่ใช่ช่องว่างล้วน
