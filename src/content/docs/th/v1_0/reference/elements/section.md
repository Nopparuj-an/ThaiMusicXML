องค์ประกอบ `<section>` กำหนดท่อนของโน้ตที่มีชื่อ

`<section>` ประกาศว่าท่อนมีอยู่และอยู่ตำแหน่งใดในลำดับการเล่น ไม่มีโน้ตอยู่ในนั้น

## องค์ประกอบแม่

- [`<structure>`](/th/v1_0/reference/elements/structure/)
- [`<repeat>`](/th/v1_0/reference/elements/repeat/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย                                                                 |
| ----------- | ------ | ------ | ------------------------------------------------------------------------ |
| `id`        | ใช่    | ID     | ตัวระบุที่ไม่ซ้ำ `<section-ref section="...">` อ้างถึง                   |
| `name`      | ไม่    | สตริง  | ป้ายสำหรับอ่าน เช่น `"ท่อน 1"` ไม่พิมพ์บนโน้ต ดู [การแสดงผล](#การแสดงผล) |

## ลูก

องค์ประกอบ [`<line-repeat>`](/th/v1_0/reference/elements/line-repeat/) ศูนย์หรือมากกว่า แต่ละตัวซ้ำช่วงบรรทัดภายในท่อน ท่อนที่ไม่มี `<line-repeat>` เล่นบรรทัดตรง ๆ

## ตัวอย่าง

```xml
<section id="s1" name="ท่อน 1" />
```

```xml
<section id="s1" name="ท่อน 1">
  <line-repeat first="2" last="3" times="2"/>
</section>
```

## หมายเหตุ

- อ้างโดย [`<section-ref>`](/th/v1_0/reference/elements/section-ref/) ในข้อมูลพาร์ต ซึ่งบรรจุโน้ตจริง
- ลำดับของท่อนในโน้ตคือตำแหน่งของมันเมื่อเทียบกับองค์ประกอบ `<section>` อื่น ๆ ใน `<structure>` ไม่มีแอตทริบิวต์แยกไว้สำหรับกำหนดลำดับ ดู [`<structure>`](/th/v1_0/reference/elements/structure/#ลำดับท่อน)
- หากต้องการเล่นท่อนซ้ำติดกัน ให้ครอบด้วย [`<repeat>`](/th/v1_0/reference/elements/repeat/) ใน `<structure>` การเล่นซ้ำเป็นคุณสมบัติของตำแหน่งที่ท่อนอยู่ในโน้ต ไม่ใช่คุณสมบัติของตัวท่อนเอง จึงไม่ใช่แอตทริบิวต์ในที่นี้
- หากต้องการเล่นอีกครั้งภายหลังโดยมีอย่างอื่นคั่น ให้ใส่ [`<play>`](/th/v1_0/reference/elements/play/) ตรงที่ท่อนนั้นกลับมา ท่อนหนึ่งประกาศด้วย `<section>` เพียงตัวเดียวไม่ว่าจะเล่นกี่ครั้ง
- เมื่อจำนวนรอบทั้งหมดของท่อนมากกว่า `1` พาร์ตอาจแปรผันรอบด้วย [`<ending>`](/th/v1_0/reference/elements/ending/)

## การแสดงผล

`name` ตั้งชื่อท่อนสำหรับไฟล์และอินเทอร์เฟซตัวแก้ไข ไม่พิมพ์เหนือกริด หัวเรื่องที่พิมพ์เช่น `สามชั้น ท่อน ๑` มาจาก [`<annotation>`](/th/v1_0/reference/elements/annotation/) ที่ผู้เรียบเรียงใส่ใน `<structure>` ก่อนท่อน ดู [ชื่อท่อน](/th/v1_0/reference/rendering/#ชื่อท่อน)
