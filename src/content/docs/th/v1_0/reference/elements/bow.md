องค์ประกอบ `<bow>` ระบุช่วงของ [`<note>`](/th/v1_0/reference/elements/note/) ที่เล่นด้วยจังหวะเดียวต่อเนื่องบนเครื่องสาย โดยไม่เปลี่ยนทิศทางตลอดช่วง

## องค์ประกอบแม่

[`<measure>`](/th/v1_0/reference/elements/measure/) หรือ [`<group>`](/th/v1_0/reference/elements/group/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| --------- | -------- | ---- | ----------- |
| `type` | ใช่ | `"start"` \| `"stop"` | ตัวเปิดหรือตัวปิดช่วง |
| `direction` | หาก `type="start"` | `"in"` \| `"out"` | ทิศทาง bow สำหรับช่วงนี้ ใช้ได้และจำเป็นเฉพาะบน `type="start"` |

## ความหมาย

`<bow type="start"/>` และ `<bow type="stop"/>` ถัดไปที่พาร์ตเข้าถึงจะครอบช่วง `<note>` ทุกตัวระหว่างเล่นด้วยจังหวะเดียวต่อเนื่อง

การจับคู่ตามลำดับเอกสารภายในรอบที่แก้ไขแล้ว ตัวในห้องหนึ่งอาจถูกปิดด้วยตัวในห้องหรือบรรทัดถัดไป ช่วงจึงข้ามขอบเขต `<measure>`, `<group>`, และ `<line>` ได้ แต่ไม่ข้ามขอบเขตท่อน

ในท่อนที่เล่นครั้งเดียว และในท่อนที่ไม่มี [`<ending>`](/th/v1_0/reference/elements/ending/) เป็นลำดับเอกสารธรรมดา เมื่อมี ending แทนที่บรรทัด แก้ไขรอบก่อนแล้วจับคู่ภายในบรรทัดที่รอบนั้นเล่นจริง ดู [ช่วงที่ข้ามบรรทัดที่ถูกแทนที่](/th/v1_0/reference/elements/ending/#ช่วงที่ข้ามบรรทัดที่ถูกแทนที่)

[`<line-repeat>`](/th/v1_0/reference/elements/line-repeat/) ไม่เกี่ยวข้อง บรรทัดถูกอ่านครั้งเดียวตามลำดับที่เขียน ไม่ว่าจะเล่นกี่ครั้ง ช่วงอาจเปิดในช่วงที่ซ้ำและปิดหลังจากนั้น

ช่วงที่ข้ามขอบเขต `<line>` ยังเป็นช่วงเดียว ตัวแสดงผลแยกเส้นโค้งเป็นสองส่วนและทำเครื่องหมายรอยต่อ ไม่เปลี่ยนข้อมูล ดู [ช่วง bow ข้ามบรรทัด](/th/v1_0/reference/rendering/#ช่วง-bow-ข้ามบรรทัด)

## ตัวอย่าง

```xml
<!-- ต่อเนื่องภายในบรรทัดเดียว ข้ามขอบเขตห้อง -->
<line number="2">
  <measure number="1">
    <bow type="start" direction="in"/>
    <note pitch="ด"/>
    <note pitch="ร"/>
  </measure>
  <measure number="2">
    <note pitch="ม"/>
    <bow type="stop"/>
    <note pitch="ซ"/>
  </measure>
</line>
```

```xml
<!-- แยกข้ามบรรทัด: แสดงผลเป็นสองส่วนโค้ง -->
<line number="3">
  <measure number="1">
    <note pitch="ล"/>
    <bow type="start" direction="out"/>
    <note pitch="ซ"/>
  </measure>
</line>
<line number="4">
  <measure number="1">
    <note pitch="ม"/>
    <bow type="stop"/>
    <note pitch="ร"/>
  </measure>
</line>
```

## การสอดคล้องมาตรฐาน

- ในทุกรอบที่แก้ไขแล้วของท่อน `type="start"` ต้องถูกปิดด้วย `type="stop"` ที่ตรงกันก่อนที่ `type="start"` อื่นจะปรากฏ ช่วง bow ไม่สามารถซ้อนหรือทับซ้อนกัน
- ในทุกรอบที่แก้ไขแล้ว `type="start"` ทุกตัวต้องมี `type="stop"` ที่ตรงกันภายใน `<section-ref>` เดียวกัน ช่วงที่เปิดค้างไว้เมื่อจบรอบไม่ถูกต้อง แม้อีกจะปิดก็ตาม
- `direction` จำเป็นบน `type="start"` และต้องไม่ปรากฏบน `type="stop"`
- ช่วง bow ไม่สามารถข้ามขอบเขต `<section>` ได้
- ช่วง bow เป็นอิสระต่อพาร์ต การระบุช่วงในโน้ตของพาร์ตหนึ่งไม่มีผลกับพาร์ตอื่น

## หมายเหตุ

- องค์ประกอบนี้อธิบายเทคนิคการสี ไม่เกี่ยวกับ tie ของโน้ตตะวันตกที่เชื่อมโน้ตสองตัวระดับเสียงเดียวกันเป็นโน้ตเดียว
