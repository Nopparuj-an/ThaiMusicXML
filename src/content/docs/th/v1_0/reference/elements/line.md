องค์ประกอบ `<line>` บรรจุบรรทัดดนตรีหรือท่วงทำนองภายในท่อน

## องค์ประกอบแม่

[`<section-ref>`](/th/v1_0/reference/elements/section-ref/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
|-----------|----------|------|-------------|
| `number` | ใช่ | จำนวนเต็ม | หมายเลขบรรทัด นับจาก 1 ภายใน `<section-ref>` ที่ครอบ |
| `id` | ไม่ | token | เอกลักษณ์ทางเลือก ต้องไม่ซ้ำกันในทุก `<line>` ของเอกสาร มีไว้ให้[ส่วนขยายเนมสเปซภายนอก](/th/v1_0/reference/elements/thai-score/#ส่วนขยาย)อ้างถึง ThaiMusicXML เองไม่ได้ใช้งาน |

## ลูก

ตามลำดับ:

- [`<annotation>`](/th/v1_0/reference/elements/annotation/) - ศูนย์หรือมากกว่า อยู่ก่อนห้อง
- [`<measure>`](/th/v1_0/reference/elements/measure/) - หนึ่งถึงแปด

แปดห้องเป็นขีดจำกัด หลายบรรทัดมีน้อยกว่า ขึ้นอยู่กับเพลง

หมายเหตุประกอบตรงนี้เป็นของบรรทัดนี้ในพาร์ตนี้ ซึ่งเป็นสิ่งที่แยกมันจากหมายเหตุประกอบบน [`<section-ref>`](/th/v1_0/reference/elements/section-ref/) ที่ครอบอยู่ หมายเหตุประกอบของ section-ref พูดถึงทั้งท่อน เช่นความหมายของรหัส `sound` ของเครื่องดนตรีหนึ่ง และพิมพ์ครั้งเดียวเหนือท่อน ส่วนหมายเหตุประกอบของบรรทัดพูดถึงบรรทัดนั้น เช่น `กรอ` เหนือช่วงที่ใช้ และพิมพ์เหนือบรรทัดนั้นไม่ว่าอยู่ตรงไหน

## การนับหมายเลข

หมายเลขบรรทัดเป็นขอบเขตภายใน `<section-ref>` ที่ครอบ เริ่มจาก `1` ในแต่ละ section reference เพิ่มทีละหนึ่งต่อบรรทัด

## การสอดคล้องมาตรฐาน

- `<line>` ต้องมี `<measure>` หนึ่งถึงแปด ตัวตรวจสอบต้องปฏิเสธบรรทัดที่มีเก้าหรือมากกว่า
- ลูก `<annotation>` ถ้ามี ต้องอยู่ก่อนห้อง ไม่ใช่คั่นระหว่างห้อง
- `number` ต้องตรงกับตำแหน่งใน `<section-ref>` นับจาก `1` บรรทัดต้องปรากฏเรียงจากน้อยไปมาก
- `id` ถ้ามี ต้องไม่ซ้ำกันในทุก `<line>` ของเอกสาร

## การแสดงผล

ช่องของห้องมีความกว้างเท่ากันตลอดทั้งโน้ต บรรทัดที่มีห้องน้อยกว่าแปดจึงแสดงผลจัดชิดซ้ายและหยุดก่อนถึงขอบ แทนที่จะยืดให้เต็มแถว ดู [กริดห้อง](/th/v1_0/reference/rendering/#กริดห้อง)

## ตัวอย่าง

```xml
<line number="1">
  <measure number="1"><note pitch="ด"/><note pitch="ร"/><note pitch="ม"/><note pitch="ร"/></measure>
  <measure number="2"><note pitch="ซ"/><note pitch="ม"/><note pitch="ร"/><note pitch="ด"/></measure>
</line>
```

```xml
<!-- พร้อมหมายเหตุถึงผู้เล่น พิมพ์เหนือบรรทัดนี้เท่านั้น -->
<line number="2">
  <annotation>กรอ</annotation>
  <measure number="1"><note pitch="ล"/><note pitch="ซ"/><note pitch="ม"/><note pitch="ร"/></measure>
</line>
```
