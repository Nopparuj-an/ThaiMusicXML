---

องค์ประกอบ `<rest>` แทนหนึ่งจังหวะที่เครื่องดนตรีไม่เล่นเสียงใหม่

โน้ตไทยไม่มีสัญลักษณ์บอกการประคองเสียง `<rest>` จึงหมายความเพียงว่าไม่มีโน้ตถูกตี ดีด หรือสีในจังหวะนั้น เสียงที่เครื่องดนตรีกำลังดังอยู่ก่อนหน้าจะดำเนินต่อไปตามการสลายตัวตามธรรมชาติของมันเอง ฆ้องยังกังวานอยู่ ส่วนระนาดเสียงหายเร็ว โน้ตไม่แยกความต่างระหว่างสองแบบนี้ และองค์ประกอบนี้ก็ไม่แยกเช่นกัน

## องค์ประกอบแม่

[`<measure>`](/th/v1_0/reference/elements/measure/) หรือ [`<group>`](/th/v1_0/reference/elements/group/)

`<measure>` ใน [พาร์ตเนื้อเพลง](/th/v1_0/reference/elements/part/#ประเภทพาร์ต) รับ `<rest>` ด้วย หมายความว่าไม่มีพยางค์ใหม่เริ่ม สระที่ร้องอยู่ดำเนินต่อ ซึ่งคือเอื้อน อ่านเหมือนข้างต้น: ไม่มีการโจมตีใหม่ ไม่ใช่ความเงียบ ดู [`<syllable>`](/th/v1_0/reference/elements/syllable/#เอื้อนและช่องว่าง)

## ตัวอย่าง

```xml
<rest/>
```

## หมายเหตุ

- องค์ประกอบปิดตัวเองไม่มีแอตทริบิวต์
- `<rest/>` แต่ละตัวใช้หนึ่งจังหวะ เท่ากับ `<note>` ที่ตำแหน่งเดียวกัน ภายใน [`<group>`](/th/v1_0/reference/elements/group/) จะได้รับส่วนแบ่งเท่า ๆ กันจากจังหวะเดียวของกลุ่ม
- ตัวหยุดพิมพ์เป็นขีดกลาง แต่บางสไตล์ปล่อยว่างไว้ในพาร์ตที่ไม่ได้คุมทำนอง ดู [ภายในห้อง](/th/v1_0/reference/rendering/#ภายในห้อง)
