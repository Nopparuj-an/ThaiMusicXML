องค์ประกอบ `<part>` กำหนดเครื่องดนตรีเดียวในวง

`<part>` ประกาศว่าเครื่องดนตรีมีอยู่และอธิบายประเภท ชื่อ และว่าซ้อนแถวกับพาร์ตอื่นหรือไม่ ไม่มีโน้ตอยู่ในนั้น

## องค์ประกอบแม่

[`<ensemble>`](/th/v1_0/reference/elements/ensemble/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| --------- | -------- | ------ | --------------------------------------------- |
| `id` | ใช่ | ID | ตัวระบุที่ไม่ซ้ำ `<part-data part="...">` อ้างถึง |
| `type` | ไม่ | สตริง | `"pitched"`, `"unpitched"`, หรือ `"lyric"` กำหนดสิ่งที่ห้องของพาร์ตนี้บรรจุ ค่าเริ่มต้น: `"pitched"` |
| `stack` | ไม่ | สตริง | เชื่อมพาร์ตนี้กับแถวอื่นของเครื่องดนตรีเดียวกัน พาร์ตที่ใช้ `stack` เดียวกันอ่านเป็นเครื่องดนตรีเดียว ละไว้สำหรับเครื่องดนตรีแถวเดียว ดู [การสอดคล้องมาตรฐาน](#การสอดคล้องมาตรฐาน) |
| `row` | หากมี `stack` | จำนวนเต็ม | ตำแหน่งของพาร์ตนี้ใน stack นับจาก `1` ด้านบน ดู [การสอดคล้องมาตรฐาน](#การสอดคล้องมาตรฐาน) |

## ลูก

- [`<instrument-name>`](/th/v1_0/reference/elements/instrument-name/) - จำเป็น
- [`<instrument-short-name>`](/th/v1_0/reference/elements/instrument-short-name/) - เป็นทางเลือก

## ตัวอย่าง

```xml
<part id="P1">
  <instrument-name>Ranat Ek</instrument-name>
</part>
```

```xml
<part id="P2" type="unpitched">
  <instrument-name>Ching</instrument-name>
</part>
```

```xml
<part id="P3" stack="khong" row="1">
  <instrument-name>ฆ้องวงใหญ่ มือขวา</instrument-name>
</part>
<part id="P4" stack="khong" row="2">
  <instrument-name>ฆ้องวงใหญ่ มือซ้าย</instrument-name>
</part>
```

```xml
<part id="P5" type="lyric">
  <instrument-name>เนื้อร้อง</instrument-name>
</part>
```

## ประเภทพาร์ต

`type` บอกว่าห้องของพาร์ตบรรจุอะไร แต่ละค่ารับองค์ประกอบต่างกัน:

| `type` | ห้องบรรจุ | โน้ตใช้ |
| --- | --- | --- |
| `pitched` | [`<note>`](/th/v1_0/reference/elements/note/), [`<rest>`](/th/v1_0/reference/elements/rest/), [`<group>`](/th/v1_0/reference/elements/group/) | `pitch` |
| `unpitched` | เหมือนกัน | `sound` |
| `lyric` | [`<syllable>`](/th/v1_0/reference/elements/syllable/), `<rest>` | n/a |

พาร์ตเนื้อเพลงเป็นพาร์ตแถวเดียวธรรมดา มีแถวในกริด อยู่ตำแหน่งที่ระบุใน [`<ensemble>`](/th/v1_0/reference/elements/ensemble/) `<instrument-name>` ตามธรรมเนียมเป็น `เนื้อร้อง` หรือ `ร้อง` เหมือนชื่อพาร์ตอื่นที่ติดป้ายแถวสำหรับตัวแก้ไขไม่ใช่พิมพ์

สิ่งที่แตกต่างคือ พาร์ตอื่นทุกพาร์ตตรงกันเรื่องจำนวนจังหวะในห้อง พาร์ตเนื้อเพลงไม่จำเป็น เสียงร้องมักไม่แบ่งเหมือนทำนอง ห้องเนื้อเพลงจึงมีเท่าที่คำต้องการ จำนวนรายการตัดสินว่าพยางค์จัดอิงจังหวะหรือจัดกลาง ดู [`<syllable>`](/th/v1_0/reference/elements/syllable/#การนับ)

ไม่มีสิ่งใดเชื่อมพาร์ตเนื้อเพลงกับดนตรีโดยอัตโนมัติ การจัดวางเป็นกลไก: ถ้าคำอยู่ใต้ระนาดเอก ก็ระบุไว้ใต้ระนาดเอก พาร์ตเนื้อเพลงอาจมี `stack` เหมือนพาร์ตอื่น ซึ่งผูกกับเครื่องดนตรีนั้นเป็นหนึ่งในแถว

## เครื่องดนตรีที่ซ้อนแถว

เครื่องดนตรีบางชนิดต้องการมากกว่าหนึ่งแถวโน้ตต่อบรรทัด เครื่องสองมือเป็นกรณีที่คุ้นเคย แถวละมือ แต่แถวไม่จำเป็นต้องเป็นมือ: เครื่องดนตรีอาจโน้ตเป็นแถวละกลุ่มสาย หรือละพื้นที่ ให้พาร์ตทุกตัวใช้ `stack` เดียวกันและหมายเลขด้วย `row`

ค่า `stack` เป็นโทเคนอิสระ ไม่พิมพ์ไม่ถึงหน้า เลือกสิ่งที่อ่านชัดในไฟล์

แถวแต่ละแถวเป็นอะไรอยู่ใน [`<instrument-name>`](/th/v1_0/reference/elements/instrument-name/) ของพาร์ตนั้น ซึ่งเป็นที่เดียวที่ไปได้ เพราะ `row` บันทึกตำแหน่งเท่านั้น เครื่องสองมือ มือขวาตามธรรมเนียมเป็นแถวบน แต่เป็นธรรมเนียมไม่ใช่กฎ ไฟล์ที่ไม่เขียน `มือขวา` ที่ใดไม่ได้บันทึกว่ามือใดเป็นอะไร

สามแถวเป็นจำนวนสูงสุดที่พบในทางปฏิบัติ ไม่มีขีดจำกัด

## หมายเหตุ

- `type` อธิบายพาร์ตไม่ใช่การแสดง ประกาศที่นี่ครั้งเดียวไม่เคยซ้ำใน `<part-data>` พาร์ตเนื้อเพลงเป็นค่าเดียวที่ไม่ใช่เครื่องดนตรีเลย เป็นการยืดคำ `<ensemble>` ที่ควรรู้: การใช้ `<part>` ซ้ำทำให้เสียงร้องมีกริดบรรทัดและห้องทั้งหมดฟรี
- ดู [`<note>`](/th/v1_0/reference/elements/note/) สำหรับวิธีที่ `type` กำหนดแอตทริบิวต์ที่โน้ตใช้
- `stack` อธิบายเครื่องดนตรีด้วย ดู [`<ensemble>`](/th/v1_0/reference/elements/ensemble/#การแสดงผล) สำหรับผลต่อการแสดงผล และ [`<link>`](/th/v1_0/reference/elements/link/) สำหรับเส้นโค้งข้ามแถวที่เปิดใช้
- พาร์ตของ stack อยู่ด้วยกันใน `<ensemble>` ตามลำดับแถว `<part-data>` ไม่เปลี่ยนและยังอ้างแต่ละพาร์ตด้วย `id`

## การสอดคล้องมาตรฐาน

- `<part>` ทุกตัวต้องมี [`<part-data>`](/th/v1_0/reference/elements/part-data/#การสอดคล้องมาตรฐาน) ตรงกันหนึ่งตัว
- `type` ต้องเป็น `"pitched"`, `"unpitched"`, หรือ `"lyric"` ตัวตรวจสอบต้องปฏิเสธค่าอื่น
- ห้องของพาร์ต `type="lyric"` ต้องมีเฉพาะ [`<syllable>`](/th/v1_0/reference/elements/syllable/#การสอดคล้องมาตรฐาน) และ `<rest>` ได้รับการยกเว้นจากกฎจำนวนจังหวะใน [`<section-ref>`](/th/v1_0/reference/elements/section-ref/#การสอดคล้องมาตรฐาน)
- `stack` และ `row` ต้องปรากฏด้วยกัน: `<part>` ที่มี `stack` ต้องมี `row` และ `<part>` ที่มี `row` ต้องมี `stack`
- ค่า `stack` ต้องใช้ร่วมกันอย่างน้อยสอง `<part>` พาร์ตเดียวเป็นเครื่องดนตรีแถวเดียวไม่มีแอตทริบิวต์ทั้งสอง
- ค่า `row` ใน stack เดียวกันต้องเริ่มจาก `1` ไม่มีช่องว่างหรือซ้ำ
- `<part>` ของ stack ต้องอยู่ติดกันใน [`<ensemble>`](/th/v1_0/reference/elements/ensemble/) ตามลำดับ `row` `row` ต้องตรงกับตำแหน่งเหมือน `number` บน [`<line>`](/th/v1_0/reference/elements/line/) และ [`<measure>`](/th/v1_0/reference/elements/measure/)
