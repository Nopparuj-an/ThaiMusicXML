องค์ประกอบ `<section-ref>` อ้างท่อนและบรรจุข้อมูลดนตรี

`<section>` ใน `<structure>` ประกาศว่าท่อนมีอยู่ ส่วน `<section-ref>` คือที่ซึ่งโน้ตของพาร์ตหนึ่งสำหรับท่อนนั้นอยู่จริง

## องค์ประกอบแม่

[`<part-data>`](/th/v1_0/reference/elements/part-data/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย                                   |
| ----------- | ------ | ------ | ------------------------------------------ |
| `section`   | ใช่    | IDREF  | อ้าง `<section id="...">` ใน `<structure>` |

## ลูก

ตามลำดับ:

- [`<annotation>`](/th/v1_0/reference/elements/annotation/) - ศูนย์หรือมากกว่า ก่อนบรรทัด
- [`<line>`](/th/v1_0/reference/elements/line/) - หนึ่งหรือมากกว่า
- [`<ending>`](/th/v1_0/reference/elements/ending/) - ศูนย์หรือมากกว่า ความแปรผันต่อรอบสำหรับท่อนที่ซ้ำ

## การนับหมายเลข

แต่ละ `<section-ref>` มีขอบเขตหมายเลขบรรทัดของตัวเอง หมายเลขบรรทัดเริ่มจาก `1` ในทุก section reference หมายเลขห้องก็เริ่มจาก `1` ในทุกบรรทัด

ลำดับท่อนในหมู่องค์ประกอบ `<section>` ใน `<structure>` ไม่กระทบหมายเลขบรรทัดหรือห้อง การซ้ำท่อนก็ไม่เปลี่ยนตัวเลขเหล่านี้

ตำแหน่งของ `<section-ref>` เองในหมู่พี่น้องก็ไม่มีความหมายเช่นกัน [`<structure>`](/th/v1_0/reference/elements/structure/#ลำดับท่อน) เป็นตัวกำหนดว่าอะไรเล่นเมื่อไร และ `section` เป็นตัวกำหนดว่าโน้ตชุดนี้เป็นของท่อนใด `<part-data>` ที่เขียน s2 ก่อน s1 จึงสื่อความหมายเท่ากับที่เขียนสลับกัน การเขียนเรียงตามลำดับที่เล่นจริงเพียงอ่านง่ายกว่าเท่านั้น

## การสอดคล้องมาตรฐาน

`<section-ref>` ที่อ้าง `<section>` เดียวกันต้องตรงกันสามอย่าง: จำนวนองค์ประกอบ `<line>` จำนวนองค์ประกอบ `<measure>` ในแต่ละบรรทัดที่ตรงกัน (จับคู่ตาม `number`) และจำนวนจังหวะในแต่ละห้องที่ตรงกัน สิ่งนี้ทำให้ห้องและจังหวะที่กำหนดตรงกับช่วงเวลาเดียวกันข้ามทุกพาร์ต ตัวตรวจสอบต้องปฏิเสธเอกสารที่ละเมิดกฎนี้

[พาร์ตเนื้อเพลง](/th/v1_0/reference/elements/part/#ประเภทพาร์ต) ผูกโดยสองอย่างแรกและได้รับการยกเว้นจากอย่างที่สาม ใช้กริดบรรทัดและห้องร่วมกับทุกอย่าง แต่ห้องมีรายการเท่าที่คำต้องการแทนจังหวะละหนึ่ง จึงไม่มีจำนวนจังหวะให้เปรียบเทียบ พาร์ตเนื้อเพลงไม่เข้าร่วมการเปรียบเทียบสำหรับพาร์ตอื่นด้วย: ห้องสี่จังหวะยังเป็นสี่จังหวะไม่ว่าแถวเนื้อเพลงด้านบนจะมีอะไร

ภายในห้อง พาร์ตเติมจังหวะอย่างไรเป็นเรื่องของพาร์ต จำนวนจังหวะเท่ากับจำนวนลูก `<note>`, `<rest>`, และ `<group>` พาร์ตหนึ่งอาจเล่นโน้ตสี่ตัวขณะที่อีกพาร์ตเล่นโน้ตหนึ่ง ตัวหยุดสอง และ `<group>` สาม ทั้งหมดรวมเป็นสี่จังหวะ ดู [`<measure>`](/th/v1_0/reference/elements/measure/#จังหวะ)

หากท่อนซ้ำ กฎใช้ต่อรอบที่แก้ไขแล้ว แก้ไข [`<ending>`](/th/v1_0/reference/elements/ending/) ของทุกพาร์ตก่อน แล้วเปรียบเทียบจำนวนข้ามพาร์ต

พาร์ตอาจละท่อนทั้งหมด หากเครื่องดนตรีเงียบตลอดท่อน 2 `<part-data>` ไม่มี `<section-ref>` สำหรับท่อนนั้น กฎข้างบนใช้เฉพาะพาร์ตที่อ้าง

`<part-data>` ต้องไม่มี `<section-ref>` สองตัวอ้าง `<section>` เดียวกัน

## ตัวอย่าง

```xml
<section-ref section="s1">
  <annotation>0 = ฉิ่ง / 1 = ฉับ</annotation>
  <line number="1">
    <measure number="1"><rest/><note sound="0"/><rest/><note sound="1"/></measure>
  </line>
</section-ref>
```
