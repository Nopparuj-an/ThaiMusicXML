องค์ประกอบ `<chord>` บรรจุสัญลักษณ์คอร์ดหนึ่งตัว

## องค์ประกอบแม่

[`<measure>`](/th/v1_0/reference/elements/measure/) ในพาร์ตที่ [`type`](/th/v1_0/reference/elements/part/) เป็น `"chord"`

## เนื้อหา

ข้อความ เขียนอย่างที่ต้องการให้พิมพ์ออกมา เช่น `Am`, `G7`, `C/E` ไม่มีสิ่งใดแยกวิเคราะห์สัญลักษณ์นี้ v1.0 บันทึกสิ่งที่ผู้เรียบเรียงพิมพ์ไว้ แล้วปล่อยให้รากคอร์ด ชนิดคอร์ด และโน้ตเบสเป็นเรื่องของคนที่อ่านหน้านั้น นี่จึงเป็นเหตุผลที่ไม่มีโปรแกรมใดย้ายคีย์พาร์ตคอร์ดได้ ค้นตามชนิดคอร์ดได้ หรือแยกคำที่พิมพ์ผิดออกจากการสะกดที่ไม่คุ้นตาได้

ดนตรีไทยไม่ได้สร้างอยู่บนโครงเสียงประสาน และพาร์ตคอร์ดก็ไม่ได้ใส่โครงนั้นเข้าไปให้ มันมีไว้สำหรับการเรียบเรียงที่มีเสียงประสานอยู่แล้ว เช่น เพลงที่เรียบเรียงให้ร้องคู่กับกีตาร์ โน้ตนำเพลงไทยสากล หรือฉบับที่ใช้สอนซึ่งเขียนแนวคลอลงไปแทนที่จะปล่อยให้คนเล่นคิดเอง

## ตัวอย่าง

```xml
<!-- คอร์ดเดียวในห้องสี่จังหวะ ตกจังหวะที่ 4 -->
<measure number="1">
  <chord>Am</chord>
</measure>
```

```xml
<!-- สองคอร์ดในห้องสี่จังหวะ ตกจังหวะที่ 3 และ 4 -->
<measure number="2">
  <chord>Am</chord><chord>G</chord>
</measure>
```

## การนับ

รายการชิดขวา ห้องที่มี *n* รายการกิน *n* จังหวะสุดท้ายของห้อง รายการละจังหวะ ส่วนจังหวะที่อยู่ก่อนหน้านั้นเว้นว่างไว้ คอร์ดตัวเดียวในห้องสี่จังหวะจึงเป็นคอร์ดบนจังหวะที่ 4 และสองตัวเป็นคอร์ดบนจังหวะที่ 3 กับ 4

ค่าเริ่มต้นนี้มาจากวิธีอ่านห้อง จังหวะมาถึงที่ช่องสุดท้ายของมัน และห้องเดินทางไปหาโน้ตตัวสุดท้าย ท้ายห้องจึงเป็นจุดที่เสียงประสานต้องไปถึงแล้ว และเป็นจังหวะที่สัญลักษณ์ตัวเดียวกำลังพูดถึง ดู [จังหวะของ `<measure>`](/th/v1_0/reference/elements/measure/#จังหวะ)

ถ้าต้องการวางคอร์ดที่อื่น ให้เติม [`<rest>`](/th/v1_0/reference/elements/rest/) ตัวหยุดกินหนึ่งจังหวะและไม่พิมพ์อะไรออกมา ตัวหยุดที่ตามหลังจึงดันสัญลักษณ์ก่อนหน้ามันให้ขยับไปทางต้นห้อง

```xml
<!-- สี่รายการ ครบทั้งสี่จังหวะ: Am บนจังหวะที่ 2 และ G บนจังหวะที่ 4 -->
<measure number="3">
  <rest/><chord>Am</chord><rest/><chord>G</chord>
</measure>
```

```xml
<!-- สองรายการ: Am บนจังหวะที่ 3 และจังหวะที่ 4 ว่าง -->
<measure number="4">
  <chord>Am</chord><rest/>
</measure>
```

ตัวหยุดที่นำหน้าไม่เปลี่ยนอะไร เพราะรายการชิดขวาอยู่แล้ว ตัวที่ขยับสัญลักษณ์คือตัวหยุดที่ตามหลังมัน

## ที่ที่ไม่ได้เขียนอะไรไว้

พาร์ตคอร์ดบันทึกการเปลี่ยนคอร์ด ไม่ใช่คอร์ดต่อจังหวะ ห้องที่ไม่มีลูกเลยหมายถึงไม่มีการเปลี่ยน คอร์ดที่เขียนไว้ล่าสุดดำเนินต่อผ่านห้องนั้นไป และไม่มีอะไรพิมพ์ออกมา `<rest>` พูดอย่างเดียวกันนี้กับจังหวะเดียว

ตรงนี้คือจุดที่แถวคอร์ดแยกทางกับแถวเนื้อร้อง ตัวหยุดในแถวเนื้อร้องคือเอื้อน เป็นสิ่งที่ผู้ร้องกำลังทำอยู่ ส่วนตัวหยุดในแถวคอร์ดเป็นการเว้นระยะ ไม่มีอะไรมากกว่านั้น

## การนับเทียบกับดนตรี

ทุกรายการอ้างสิทธิ์หนึ่งจังหวะ ห้องคอร์ดจึงมีรายการได้ไม่เกินจำนวนจังหวะของห้องนั้น ห้องคอร์ดห้ารายการที่วางทับห้องสี่จังหวะมีรายการหนึ่งที่ไม่มีที่ไป และตัวตรวจสอบจะปฏิเสธ

[พาร์ตเนื้อร้อง](/th/v1_0/reference/elements/part/#ประเภทพาร์ต) ไม่มีเพดานแบบนี้ ความต่างนี้ตั้งใจ คำร้องมักไม่แบ่งเหมือนทำนอง ห้องเนื้อร้องจึงเป็นอิสระจากกริดจังหวะ และบอกเช่นนั้นด้วยจำนวนที่ไม่ตรงกัน ส่วนสัญลักษณ์คอร์ดเป็นการอ้างถึงจังหวะใดจังหวะหนึ่งเสมอ จึงอยู่บนกริด

ใต้เพดานนั้น พาร์ตคอร์ดได้รับการยกเว้นจากกฎจำนวนจังหวะเท่าที่พาร์ตเนื้อร้องได้รับ มันใช้กริดบรรทัดและห้องร่วมกับพาร์ตอื่นทุกพาร์ต และไม่มีส่วนกำหนดว่าจำนวนจังหวะเป็นเท่าไร ดู [`<section-ref>`](/th/v1_0/reference/elements/section-ref/#การสอดคล้องมาตรฐาน)

## การสอดคล้องมาตรฐาน

- `<chord>` ใช้ได้เฉพาะภายใน `<measure>` ในพาร์ตที่ `type` เป็น `"chord"`
- ห้องของพาร์ตคอร์ดต้องมีเฉพาะลูกที่เป็น `<chord>` และ `<rest>` `<note>`, `<group>`, `<syllable>`, `<bow>`, `<parenthesis>`, และ `<link>` ใช้ที่นั่นไม่ได้
- เนื้อหาของ `<chord>` ต้องไม่ว่าง
- จำนวนรายการในห้องคอร์ดต้องไม่เกินจำนวนจังหวะของห้องที่ตรงกันในพาร์ตที่มีโน้ต จะน้อยกว่าก็ได้ และเป็นศูนย์ก็ได้
- พาร์ตคอร์ดยังต้องตรงกับพาร์ตอื่นทุกพาร์ตเรื่องจำนวนบรรทัดและจำนวนห้องในแต่ละบรรทัด
- พาร์ตคอร์ดต้องไม่มี `stack` หรือ `row`
