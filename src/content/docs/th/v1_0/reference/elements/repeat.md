องค์ประกอบ `<repeat>` ครอบเนื้อหา `<structure>` และเล่นมากกว่าหนึ่งครั้ง การซ้ำอาจซ้อนกันได้ เพลงจึงประกอบขึ้นจากหลายชั้นของการซ้ำ

## องค์ประกอบแม่

- [`<structure>`](/th/v1_0/reference/elements/structure/)
- [`<repeat>`](/th/v1_0/reference/elements/repeat/) - repeat อาจครอบ repeat อื่น

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| --------- | -------- | ------- | -------------------------------------------------- |
| `times` | ไม่ | จำนวนเต็ม | จำนวนครั้งที่เนื้อหาที่ครอบเล่น ค่าเริ่มต้น: `1` |

## ลูก

ลูกเดียวกับที่ `<structure>` รับ ลำดับใดก็ได้และซ้ำได้อิสระ:

- [`<annotation>`](/th/v1_0/reference/elements/annotation/)
- [`<br>`](/th/v1_0/reference/elements/br/)
- [`<direction>`](/th/v1_0/reference/elements/direction/)
- [`<section>`](/th/v1_0/reference/elements/section/)
- [`<repeat>`](/th/v1_0/reference/elements/repeat/)

## ความหมาย

ทุกอย่างภายใน `<repeat>` เล่น `times` รอบก่อนที่โน้ตจะดำเนินต่อไป การครอบสองท่อนไว้ด้วยกันจะซ้ำทั้งคู่พร้อมกัน ได้ผลเป็น `A B A B` ซึ่งต่างจากการซ้ำแต่ละท่อนแยกกัน

เมื่อ repeat ซ้อนกัน จำนวนครั้งจะคูณกัน ท่อนที่ครอบด้วย `times="2"` ซ้อนอยู่ในอีก `times="2"` จะเล่นสี่ครั้ง

```xml
<structure>
  <repeat times="2">
    <repeat times="2">
      <section id="s1" name="ท่อน 1" />
    </repeat>
    <section id="s2" name="ท่อน 2" />
  </repeat>
</structure>
```

เล่นท่อน 1 สองครั้ง แล้วท่อน 2 หนึ่งครั้ง จากนั้นเล่นทั้งคู่ซ้ำอีกรอบ รวมเป็นสี่ห้องของท่อน 1 และสองห้องของท่อน 2 เรียงตามลำดับ 1 1 2 1 1 2

### จำนวนรอบทั้งหมด

จำนวนรอบทั้งหมดของท่อนคือผลคูณของค่า `times` ของ `<repeat>` ทุกตัวที่ครอบ หรือ `1` หากไม่มี ในตัวอย่างข้างบน ท่อน 1 มีรอบทั้งหมด 4 และท่อน 2 มี 2

การนับรอบเป็นแบบสัมบูรณ์ ตั้งแต่ครั้งแรกไปจนถึงครั้งสุดท้าย โดยไม่สนว่ารอบนั้นเกิดจาก repeat ชั้นไหน แอตทริบิวต์ `pass` ของ [`<ending>`](/th/v1_0/reference/elements/ending/) ใช้ตัวเลขสัมบูรณ์นี้ `pass="4"` บนท่อน 1 ข้างต้นจึงหมายถึงครั้งสุดท้ายในสี่ครั้ง และ `pass="2,4"` หมายถึงสองในสี่ครั้งนั้น

## ลำดับท่อน

`<repeat>` ไม่ได้เปลี่ยนวิธีอ่านลำดับท่อน ลำดับยังคงเป็นลำดับที่องค์ประกอบ `<section>` ปรากฏในเอกสาร ไล่แบบ depth-first ผ่านชั้น `<repeat>` ที่ครอบอยู่ ดู [`<structure>`](/th/v1_0/reference/elements/structure/#ลำดับท่อน)

## การสอดคล้องมาตรฐาน

- `times` ต้องเป็นจำนวนเต็ม `1` ขึ้นไป
- `<repeat>` ต้องมี `<section>` อย่างน้อยหนึ่งตัว ไม่ว่าโดยตรงหรืออยู่ใน `<repeat>` ที่ซ้อนอยู่ข้างใน repeat ที่ครอบเฉพาะ annotation และ direction ไม่มีอะไรให้เล่นเลย
- การซ้ำซ้อนลึกเท่าใดก็ได้
- หากต้องการซ้ำช่วงบรรทัดภายในท่อนเดียวแทนท่อนทั้งหมด ใช้ [`<line-repeat>`](/th/v1_0/reference/elements/line-repeat/)
