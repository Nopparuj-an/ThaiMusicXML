องค์ประกอบ `<line-repeat>` ซ้ำช่วงบรรทัดติดกันภายในท่อน โดยไม่ซ้ำท่อนทั้งหมด

## องค์ประกอบแม่

[`<section>`](/th/v1_0/reference/elements/section/)

## แอตทริบิวต์

| แอตทริบิวต์ | จำเป็น | ประเภท | คำอธิบาย |
| --------- | -------- | ------- | ---------------------------------------- |
| `first`   | ใช่ | จำนวนเต็ม | หมายเลขบรรทัดแรกที่ซ้ำ นับจาก 1 |
| `last`    | ใช่ | จำนวนเต็ม | หมายเลขบรรทัดสุดท้ายที่ซ้ำ (รวม) นับจาก 1 |
| `times`   | ไม่ | จำนวนเต็ม | จำนวนครั้งที่เล่น ค่าเริ่มต้น: `1` |

## ความหมาย

ทุกครั้งที่การเล่นมาถึงบรรทัด `first` บรรทัด `first` ถึง `last` จะเล่นซ้ำ `times` ครั้งก่อนดำเนินต่อไปหลัง `last` หากตั้ง `first` และ `last` เป็นเลขเดียวกัน ก็จะเป็นการซ้ำบรรทัดเดียว

การซ้ำบรรทัดเป็นอิสระจาก [`<repeat>`](/th/v1_0/reference/elements/repeat/) ที่ครอบท่อนอยู่ โดยซ้อนอยู่ข้างในนั้น และจะเริ่มทำงานใหม่ทั้งหมดในทุกรอบของท่อน รวมถึงรอบที่สองและรอบต่อ ๆ ไป

ท่อนหนึ่งอาจมี `<line-repeat>` หลายตัวครอบช่วงบรรทัดต่างกัน เมื่อช่วงหนึ่งซ้อนอยู่ในอีกช่วง ช่วงในจะเล่นจนจบทุกครั้งที่ช่วงนอกวนมาถึง

## ตัวอย่าง

```xml
<section id="s1" name="ท่อน 1">
  <line-repeat first="2" last="3" times="2"/>
</section>
```

บรรทัด 2 และ 3 จะเล่นสองครั้งก่อนที่ท่อนจะดำเนินต่อไปยังบรรทัด 4 หาก `<repeat>` ใน `<structure>` เล่นท่อนนี้ซ้ำสองรอบ เหตุการณ์นี้จะเกิดขึ้นทั้งสองรอบ

## การแสดงผล

การซ้ำบรรทัดพิมพ์เป็นวงเล็บในขอบขวากริด ครอบแถวที่ซ้ำและติดป้าย ซ้ำ ดู [วงเล็บซ้ำ](/th/v1_0/reference/rendering/#วงเล็บซ้ำ)

## การสอดคล้องมาตรฐาน

- `first` และ `last` จำเป็นทั้งคู่ `first` ต้องไม่มากกว่า `last`
- `times` ต้องเป็นจำนวนเต็ม `1` ขึ้นไป
- `last` ต้องไม่เกินจำนวนองค์ประกอบ `<line>` ในเนื้อหา `<section-ref>` ของท่อน เมื่อไม่มี [`<part-data>`](/th/v1_0/reference/elements/part-data/) อ้างท่อนเลย ไม่มีจำนวนบรรทัดให้ตรวจสอบ กฎนี้จึงไม่ใช้ ท่อนดังกล่าวไม่มีดนตรี ไม่สร้างแถวในหน้า ไม่เล่น
- `<line-repeat>` ไม่มีผลต่อการจับคู่ช่วง [`<bow>`](/th/v1_0/reference/elements/bow/) และ [`<parenthesis>`](/th/v1_0/reference/elements/parenthesis/) ช่วงเหล่านั้นอ่านบรรทัดครั้งเดียวตามลำดับเอกสารไม่ว่าจะเล่นกี่ครั้ง
- ช่วง `<line-repeat>` สองช่วงใน `<section>` เดียวกันต้องซ้อนกันอย่างถูกต้องหรือแยกกันทั้งหมด ช่วงที่ทับซ้อนบางส่วนไม่ถูกต้อง และสองตัวที่ครอบช่วงเดียวกันก็ไม่ถูกต้อง: รวมเป็นตัวเดียวที่ `times` สูงกว่า
- ค่า `pass` ของ [`<ending>`](/th/v1_0/reference/elements/ending/) นับรอบของท่อน ไม่ใช่รอบของการซ้ำบรรทัด ending ที่แทนที่บรรทัดในช่วงที่ซ้ำใช้กับทุกครั้งที่ช่วงนั้นเล่นในรอบที่ระบุ
