# ThaiMusicXML v0.1

Welcome to ThaiMusicXML v0.1 documentation.

## What is ThaiMusicXML?

ThaiMusicXML is a library for working with MusicXML files containing Thai music notation.

## Quick Start

Install ThaiMusicXML:

```bash
npm install thaimusicxml
```
